# 수업 진행 가이드

강사용 문서입니다. 저장소에 함께 포함해 배포하며, 에이전트는 사용자가 요청하지 않으면 이 폴더를 읽지 않습니다. 시간 배분은 강의 시간에 맞춰 조정하세요. 아래 흐름과 표의 내용은 이 프로젝트를 만든 시점의 계획이며, 실제 수업에서 시험한 결과가 아닙니다 `[확인 필요]`.

## 진행 흐름 제안

1. **고민 꺼내기:** [사례집](../docs/01_사례집.md)에서 가까운 고민을 고르게 합니다. 처음이면 [시작하기](../docs/00_시작하기.md)를 함께 읽습니다.
2. **작은 목표 고르기:** 에이전트가 제안한 방법과 결과 중에서 수강생이 직접 고르게 합니다.
3. **자료 준비:** 있는 자료를 쓰거나 대화로 만듭니다. 개인정보는 [체크리스트](../docs/reference/개인정보_체크리스트.md)로 먼저 점검합니다.
4. **첫 결과 만들기:** 에이전트가 만든 결과와 저장 위치를 같이 확인합니다.
5. **직접 확인:** 날짜·숫자·담당자를 원문과 대조하게 합니다. 이 단계가 사람의 일이라는 점을 강조합니다.
6. **고치기:** 아쉬운 점을 말로 설명해 고치게 합니다. [고쳐 가는 과정 예시](../docs/reference/고쳐_가는_과정.md)를 보여 줘도 좋습니다.
7. **남기기:** 경험 기록을 `outputs/`에 저장하고, 에이전트가 `agents_logs/INDEX.md`에 줄을 남겼는지 같이 봅니다.
8. **다음 시간에 이어 가기:** 새 대화에서 색인을 보고 이어 가는 경험을 하게 합니다.

수업 중 칠판에 "사람의 일 / 에이전트의 일" 두 칸을 그려 두면 좋습니다. 사람은 목표·방법·수정을 고르고 중요한 내용을 확인하고, 에이전트는 질문·자료 정리·초안·저장을 맡습니다.

## 자주 막히는 곳

| 증상 | 가능한 원인 | 해 볼 것 |
| --- | --- | --- |
| 폴더 지정 메뉴가 안 보인다 | 프로젝트 기능과 폴더 연결은 다른 기능이다 | 폴더를 읽고 쓰는 연결(커넥터 등)을 쓸 수 있는 도구인지 확인한다 `[확인 필요]` |
| 에이전트가 지침을 안 따르는 것 같다 | 지침 파일을 읽지 않았다 | "`AGENTS.md`를 읽고 따라 줘"라고 말한다. 도구가 `CLAUDE.md` 등 다른 이름을 읽는지 확인한다 |
| 파일이 저장되지 않는다 | 폴더 연결이나 저장 권한이 없다 | 에이전트가 알렸는지 확인한다. 안 되면 결과를 대화로 받아 직접 저장한다 |
| 링크를 못 읽는다 | 도구가 해당 사이트에 접근하지 못한다 | 본문을 붙여 넣거나 다른 도구에서 정리한 내용을 "중간 자료"로 저장한다 |
| 지난 작업을 못 찾는다 | `INDEX.md`가 없거나 비어 있다 | "`agents_logs/INDEX.md`를 보고 이어서 하자"라고 말한다 |
| 모델 이름을 묻는다 | 에이전트가 자기 모델 이름을 모른다 | 앱 화면의 모델 이름을 알려 준다. 모르면 `모델미확인`으로 쓴다 |
| 한글 이미지가 깨진다 | 이미지 도구가 한글에 약하다 | 배경과 그림만 만들고 글자는 편집 도구에서 넣는다 |
| 사용량 한도에 걸린다 | 긴 자료와 긴 대화 | 작은 단계로 나누고 긴 자료는 필요한 부분만 쓴다 `[확인 필요]` |
| 개인정보를 올렸다 | 가리지 않고 올렸다 | [체크리스트](../docs/reference/개인정보_체크리스트.md)의 "실수로 올렸다면"을 따른다 |
| 다른 AI로 옮기고 싶다 | 도구마다 대화 기록이 따로 있다 | 같은 프로젝트 폴더를 열고 색인과 `outputs/`로 이어 간다 |
