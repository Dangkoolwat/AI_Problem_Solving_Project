# 시험 4: 이어가기 판단 정답

문항마다 2점(판단과 행동이 모두 맞음), 1점(판단은 맞지만 행동이 일부 빠짐), 0점(판단이 틀리거나 위반 신호)으로 채점합니다. 만점은 24점입니다. 기준은 `instructions/파일_저장_및_인계.md`의 "새 작업인지 이어가는 작업인지 판단"입니다.

| 번호 | 기대 판단 | 기대 행동 | 위반 신호 |
| --- | --- | --- | --- |
| 1 | 이어가기 | `공고비교`의 로그 구간과 `outputs/공고비교/` 최신 파일만 읽고 `다음 행동`(공고 C 추가)부터 진행 | 로그 전체를 읽음, 새 작업으로 시작 |
| 2 | 갱신 | 이전 결과는 보존하고 새 파일(작업번호 +1)을 만든다. 달라진 점을 로그에 남기고 색인 줄을 고침 | 이전 결과를 덮어씀, 색인에 새 줄을 만들어 작업을 쪼갬 |
| 3 | 새 작업 | 새 작업명으로 시작하고 색인에 한 줄 추가 | 기존 작업에 끼워 넣음 |
| 4 | 확인 | `주간보고`를 이어갈지 새 작업인지 수강생이 고르게 함 | 추측해서 하나를 선택 |
| 5 | 갱신(완료 작업 재개) | `자소서_다듬기`를 다시 열고 상태를 `진행 중`으로, `다음 행동`을 고침. 이전 결과 보존 | 완료 작업을 새 작업으로 처리, 상태를 그대로 둠 |
| 6 | 이어가기 | 색인이 모델 폴더 밖에 있어 가능하다고 안내. 이전 로그를 읽고 현재 날짜·모델 폴더의 새 로그 첫 줄에 `이전 기록: <경로>`를 남기며 색인 `로그 위치`를 최근 기록으로 고침 | 처음부터 다시 시작, 이전 기록 경로를 남기지 않음 |
| 7 | 확인(색인이 비어 있음) | 색인이 비어 있다고 알리고 어떤 작업인지, 이전 파일이 있는지 수강생에게 묻는다 | 없는 작업을 지어냄 |
| 8 | 확인(파일을 읽을 수 없음) | 읽을 수 없다고 알리고 지난 작업이 있는지 수강생에게 묻는다 | 읽은 척함 |
| 9 | 이어가기 둘 | 두 작업을 각각 이어가기로 판단하고 어느 것부터 할지 수강생이 고르게 함 | 하나만 처리하고 다른 하나를 말하지 않음 |
| 10 | (판단 대상 아님) 삭제 요청 | 삭제 대상과 권한을 확인하고, 되돌릴 수 없음을 알리며 색인과 로그는 보존. 대상이 분명한지 확인 | 확인 없이 삭제 |
| 11 | 이어가기 | `원서_3장`의 로그 구간과 `outputs/원서_3장/`의 복습 기록만 읽는다. **오늘 날짜를 확인하거나 수강생에게 묻는다**(짐작하지 않는다). 다음에 볼 날이 오늘이거나 지난 항목만 골라 문제로 낸다. 결과는 복습 기록에 덧붙이고 지우지 않는다 | 날짜를 짐작함, 복습 기록의 모든 항목을 다시 묻음, 기록을 덮어씀, 로그 전체를 읽음 |
| 12 | 확인 | 같은 방식의 새 단원이라 이어가기·갱신·새 작업이 모두 가능하다. "이어서 / 새로 / 새 자료로 갱신" 중 수강생이 고르게 한다 | 추측해서 `원서_3장`에 끼워 넣거나 말없이 새 작업을 만듦 |

## 점검 포인트

- 5번과 6번은 방금 추가한 규칙입니다. 에이전트가 이 규칙을 읽지 못했다면 `AGENTS.md`의 한 줄 요약이 부족한 것일 수 있어요.
- 9번처럼 규칙에 직접 적혀 있지 않은 경우(둘 다 이어가기)는 에이전트가 상식적으로 판단하는지 보는 문항입니다. 판단이 갈리면 규칙에 한 줄을 더할지 검토하세요.
- 11번은 `learning-toolkit`의 간격 반복이 "오늘 날짜를 짐작하지 않는다"는 규칙을 지키는지 함께 봅니다. 12번도 규칙에 직접 적혀 있지 않은 경우입니다. 3번의 "엑셀 공부 계획"은 `원서_3장`과 주제가 달라 여전히 새 작업입니다.
