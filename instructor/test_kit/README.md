# 시험 키트

이 작업공간의 지침과 스킬이 **다른 에이전트에게도 제대로 이해되고 동작하는지** 확인하는 시험 모음입니다. 어떤 에이전트(Claude, ChatGPT, Gemini, Codex 등)에게든 줄 수 있게 만들었어요. 강사뿐 아니라 자기만의 지침·스킬을 만들어 보고 싶은 수강생도 "에이전트 동작을 이렇게 점검하는구나" 하고 참고할 수 있도록 함께 공개해 둔 예시입니다(평소 작업 중에는 에이전트가 읽지 않으며, `결과/` 폴더만 `.gitignore`로 제외됩니다).

## 순서

1. **기준선 측정:** 지금 상태 그대로 시험하고 결과를 남깁니다.
2. **수정:** 점수가 낮은 문항을 보고 지침·스킬을 고칩니다.
3. **재측정:** 같은 시험을 다시 돌려 점수가 올랐는지, 새로 틀린 문항이 없는지 비교합니다.

## 시험 보는 에이전트에게 줄 때

- 문제 파일의 **내용을 대화에 붙여 넣어** 주세요. 정답·채점 파일이 있는 폴더를 열어 두면 에이전트가 정답을 볼 수 있어요. 시험은 `instructor/` 폴더를 뺀 복사본에서 하세요.
- 이해도·스킬 적합·이어가기·학습 스킬 시험은 이렇게 시작하세요.

```text
지금부터 시험입니다. 이 작업공간의 AGENTS.md는 읽어도 됩니다.
파일은 만들거나 고치지 마세요. 아래 문제에 하나씩 답해 주세요.
읽어야 한다고 판단한 파일이 있으면 경로를 적고, 마지막에 시험 중 읽은
파일 이름을 한 줄로 알려 주세요. (문제 붙여 넣기)
```

- 시험 1(이해도)은 `AGENTS.md`를 읽게 하고, 에이전트가 `AGENTS.md` 8절 표를 따라 필요한 파일을 직접 찾아 읽는 것은 허용합니다. 17·18번은 `.skills/thinking-toolkit/` 안의 파일을 읽어야 기대 행동을 모두 할 수 있습니다. 시험 3·4는 `AGENTS.md`와 각 스킬의 메뉴(SKILL.md 위쪽)를 읽게 해도 됩니다. 시험 5(학습 스킬)는 `AGENTS.md`와 `.skills/learning-toolkit/` 안의 파일을 읽게 해도 됩니다(문제 첫머리에 적혀 있습니다). 무엇을 읽게 했는지 결과에 적어 주세요.
- **시험 2(시뮬레이션)는 프로젝트를 통째로 복사한 폴더에서만** 하세요. 시험 중 `outputs/`, `agents_logs/`에 파일이 생깁니다. 원본 폴더에서 하면 색인과 결과가 어지러워져요.

## 채점과 기록

- 문항마다 **2점**(기대 행동을 모두 함), **1점**(일부만 함), **0점**(위반 신호가 보임)으로 채점합니다. 채점은 사람이 하거나, 시험을 보지 않은 다른 에이전트에게 채점 기준을 주고 맡길 수 있어요.
- 결과는 `06_결과_기록_양식.md`를 복사해 `결과/날짜_시험이름_모델이름.md`로 저장합니다. 모델 이름을 모르면 `모델미확인`으로 적으세요.
- 토큰 사용량은 앱이 보여 줄 때만 적고, 없으면 `미확인`으로 둡니다. 읽은 파일 목록은 에이전트가 알려 준 대로 적습니다.

## 주의

- 여러 에이전트를 돌리면 사용량이 많이 듭니다. 처음에는 시험 1의 문항 6개, 시험 4의 문항 5개, 시험 5의 문항 5개(3·5·7·11·12번) 정도로 시작하세요.
- 에이전트마다 지침 파일을 자동으로 읽는지가 다릅니다. 자동으로 안 읽는 도구는 "AGENTS.md를 읽고 시작해"라고 말한 결과로 시험하고, 그 사실도 결과에 적어 주세요.
- 이 키트의 점수는 지침을 고치는 데 쓰는 참고값입니다. 실제 수업에서의 이해도와 같다고 볼 수는 없어요.
