# 고치는 정도와 말투

> 이 파일은 `.skills/humanize-korean/SKILL.md`의 세부 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

## 고치는 정도

| 단계 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 1) 맞춤법·띄어쓰기만 | 분명한 오탈자, 띄어쓰기, 조사, 문장 호응을 고친다 | 표현과 문장 구조를 바꾸지 않는다 |
| 2) 어색한 문장만 | 어색하거나 읽기 어려운 문장만 고친다 | 잘 읽히는 문장은 손대지 않는다 |
| 3) 자연스럽게 다듬기 | 뜻과 말투를 지키면서 문장과 문단의 흐름을 고른다. 따로 정하지 않았을 때의 기본이다 | 문단 순서를 바꾸거나 내용을 덜어 내지 않는다 |
| 4) 전체 흐름까지 | 문단 순서, 연결, 중복까지 정리한다 | 핵심 내용과 사실을 바꾸지 않는다 |
| 5) 짧게 압축 | 중복과 군더더기 설명을 줄인다 | 핵심 정보와 뜻을 빼지 않는다 |
| 6) 중복을 줄이고 구조까지 | 되풀이되는 내용을 합치고 문단 구조와 순서를 조정한다 | 뜻이 달라지는 큰 삭제는 마음대로 하지 않고 먼저 묻는다 |

4~6단계에서 문단을 옮기거나 내용을 덜어 냈으면 무엇을 옮기고 줄였는지 수정 예시에 함께 적는다.

## 친구에게 쓰는 글, 친근한 말투

읽는 사람이 친구이거나 사용자가 격식 없는 말투를 원할 때 따른다.

- **대화체 어미:** "~한다", "~이다", "~니?", "~하는구나" 같은 교과서식 반말을 피하고, 메신저나 일상 대화에서 쓰는 "~해", "~했어", "~지", "~잖아"를 쓴다.
- **대명사:** "당신은", "나는", "본인은"을 줄인다. 주어는 자연스럽게 생략하고, 꼭 필요하면 "너", "나"로 부른다.
- **감정 표현:** "아", "진짜", "근데", "와" 같은 감탄사와 말줄임표, 물결표, 느낌표는 글의 분위기에 맞으면 쓴다. 원문에 "ㅋㅋ", "ㅎㅎ"나 이모티콘이 없으면 새로 넣지 않고 원문의 분위기에 맞춘다.

## 높임말을 쓰는 글

- 한 글 안에서 높임 단계가 섞여 있으면 하나로 맞춘다. 어느 쪽으로 맞출지는 원문에 더 많이 쓰인 쪽이나 사용자가 고른 말투를 따른다.
- "확인하시어 참고 부탁드립니다"처럼 지나친 높임은 "아래 내용을 확인해 주세요"처럼 자연스러운 정중함으로 고친다.

## 자기소개서와 경험을 쓰는 글

- 어떤 상황이었는지, 내가 무엇을 했는지, 무엇이 달라졌거나 무엇을 배웠는지가 순서대로 읽히게 다듬는다.
- 결과가 숫자로 확인된 경우에만 숫자를 쓴다. 숫자가 없으면 본 것과 배운 것으로 마무리한다. 숫자를 요구하거나 만들어 넣지 않는다.
- "열정적으로", "최선을 다해" 같은 자기 평가는 사용자가 한 행동으로 바꿔 쓸 수 있을 때만 바꾸고, 행동이 원문에 없으면 사용자에게 묻는다.
- 글자 수와 문항 조건을 모르면 `[확인 필요]`로 둔다.
