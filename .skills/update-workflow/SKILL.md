# 새 자료로 결과 이어서 갱신하기

취업공고, 업무 기록, 표 자료, 보고서나 개인 관심사 등에서 새 자료를 이전 결과에 반영할 때 사용한다. 먼저 사용자가 원하는 갱신 대상과 기존 자료·결과를 살핀다. 필요한 연결이 불분명하면 확인할 자료나 결과를 물어보고, 이미 정해진 대상과 방법은 다시 고르게 하지 않는다. 지난 결과가 없다면 있는 자료로 시작하는 방법을 제안한다.

## 새 자료와 기존 결과 연결

1. `instructions/자료_마련과_저장.md`와 저장 지침에 따라 새 자료를 보관·저장하고 읽을 수 있는지 확인한 뒤 분석한다. 원문·사람의 기록·AI 정리본, 출처와 날짜, 확인한 범위를 구분한다.
2. 이전 자료·결과·업무 기록에서 확인할 수 있는 연결과 확인 날짜를 살핀다. 비교 가능한 이전 내용이 없거나 접근할 수 없으면 알리고, 차이를 추측하지 않는다. 확인한 범위에서 추가·변경·유지·미확인 내용을 구분한다. 접근 실패는 변경 없음이 아니다.
3. 어떤 결과에 영향이 있는지 설명한다. 예를 들어 새 공고에 맞는 지원 자료, 새 자료를 반영한 보고서, 데이터가 바뀐 표나 대시보드를 만들 수 있다. 사용자의 목표에 따라 필요한 결과를 고르거나 이미 지정한 결과를 갱신한다. 엑셀·대시보드는 실제 파일 구조와 현재 도구에 따라 새 데이터를 읽거나 새 결과를 만드는 방법을 정하며, 화면이나 수식이 자동 갱신됐다고 가정하지 않는다.
4. 이전 원본·중간 자료·결과를 보존하고, `instructions/파일_저장_및_인계.md`에 따라 새 결과를 구분해 저장한다. 적용한 자료·출처와 날짜, 이전 결과와 달라진 점, 반영하지 못한 부분과 사람이 확인할 항목을 Markdown 기록으로 남긴다. 무엇이 확인되었는지와 제안이나 미확인을 구분한다.

자동 감시·예약 실행·외부 알림은 이 과정만으로 시작되지 않는다. 실제 도구·권한과 사용자의 지시를 확인하고, 예약이나 전달이 필요한 경우 별도로 준비한다. 필요하면 표 자료는 `.skills/data-toolkit/SKILL.md`, 취업·업무는 해당 툴킷과 함께 사용한다.
