# 인포그래픽 도구 상자

## 제작 전 사전 확인

인포그래픽 작업을 시작할 때 사용할 자료와 Markdown 중간 초안이 있는지 반드시 물어본다. 이미 제공하거나 확인한 내용은 짧게 정리하고 같은 정보를 다시 요구하지 않는다. 질문은 필요한 만큼 나누고, 답을 기다리는 동안 자료 준비 방법은 안내할 수 있다.

초안이 있으면 위치와 내용을 확인한다. 없다면 사용자가 제공한 자료나 대화를 바탕으로 제목·핵심 내용·정확한 문구·숫자·출처를 담은 Markdown 초안을 함께 마련한다. 분석에 사용할 자료와 초안은 `data/`에 저장하고 읽을 수 있는지 확인한다. 사용자가 초안의 내용을 확인할 수 있게 보여 주고 답을 받은 뒤 이미지 제작을 시작한다. 자료를 저장하거나 읽을 수 없으면 상황을 알리고 해당 자료의 분석과 이미지 제작을 보류한다.

사용자의 목적과 대상, 자료를 듣고 적합한 구성과 각 결과를 쉬운 말로 설명한다. 사용자는 한 가지나 여러 가지를 고르거나 다른 방식을 제안할 수 있다. 요청이 없어도 자료와 목적에 맞아 보이는 구성 하나를 의견과 이유로 짧게 밝히고, 선택은 사용자에게 맡긴다. 조건이 충분하면 이미 정한 사항을 다시 묻지 않는다. 질문은 필요한 만큼 나누고, 아래 구성은 예시로 활용한다.

| 구성 | 언제 | 기본 배치와 결과 |
| :--- | :--- | :--- |
| 핵심 요약형 | 긴 내용에서 중요한 점을 전달할 때 | 제목과 핵심 내용 몇 가지를 나누어 한눈에 보여 준다. |
| 단계 안내형 | 절차나 방법을 설명할 때 | 순서와 짧은 설명을 세로 또는 가로로 이어 보여 준다. |
| 비교형 | 선택지나 전후 차이를 살필 때 | 같은 기준으로 나란히 배치해 차이를 보여 준다. |
| 숫자 강조형 | 자료의 수치와 의미를 전달할 때 | 확인된 핵심 숫자와 단위, 설명을 강조한다. |
| 타임라인형 | 일정이나 시간에 따른 변화를 보여 줄 때 | 확인된 날짜와 사건을 시간순으로 배치한다. |

사용처에 맞는 비율·크기, 대상에 맞는 분위기와 정보량을 제안한다. 예를 들어 세로 안내문, 가로 발표 화면, 정사각형 게시물을 선택할 수 있다. 사용자의 조건이 우선이며, 선택한 형식에 필요한 정보가 부족하면 빠진 점과 보완 방법을 알린다. 확인하지 못한 숫자·날짜·출처는 만들지 않는다.

## 이미지 분위기 고르기

구성과 별도로 이미지 분위기를 선택할 수 있게 한다. 자료와 대상에 어울리는 선택지 몇 가지를 골라 색·그림의 느낌과 예상 결과를 설명한다. 사용자는 하나나 여러 개를 골라 비교하거나 직접 원하는 분위기를 말할 수 있다. 이미 정한 분위기는 다시 묻지 않는다.

| 분위기 세트 | 색·그림과 결과 | 활용 예 |
| :--- | :--- | :--- |
| 깔끔한 업무 보고 | 흰색·남색, 넉넉한 여백과 단순한 도형으로 정돈된 화면 | 보고서·회의 자료 |
| 밝고 친근한 일러스트 | 밝은 색, 부드러운 그림과 둥근 도형으로 편안한 화면 | 생활 정보·학습 안내 |
| 차분하고 따뜻한 감성 | 베이지·녹색 등 부드러운 색과 편안한 그림 | 독서 기록·일상 |
| 선명한 포스터 | 대비가 뚜렷한 색과 큼직한 도형으로 메시지 강조 | 행사 안내·핵심 메시지 |
| 손그림 노트 | 종이 느낌 배경과 낙서·손그림으로 메모 같은 화면 | 아이디어·공부 기록 |
| 인스타 감성 | 은은한 사진이나 빛·종이 질감 배경, 날렵한 글자와 여백으로 감각적인 화면 | 카드뉴스·짧은 이야기·개인 기록 |

세트는 예시이며 색, 그림과 분위기를 바꾸거나 조합할 수 있다. 같은 구성에 여러 분위기를 적용하거나 다른 구성을 선택해 비교할 수 있다. 대상과 목적에 맞는 대비·여백·가독성을 함께 고려한다.

인스타 감성 예시 요청문: “은은한 햇빛과 차분한 색감의 배경에 넉넉한 여백을 두고, 날렵하고 정돈된 글자로 핵심을 강조해 줘. 글자가 배경에 묻히지 않게 해 줘.” 사진·색감·질감은 주제와 사용자의 취향에 맞게 바꾼다. 정확한 한글은 이미지에서 확인하거나 빈 공간에 편집 도구로 따로 넣는 방법을 제안한다.

## 내용과 이미지 만들기

- 자료가 필요하면 `instructions/자료_마련과_저장.md`를 따른다. 실제 확보한 원본과 분석용 자료를 구분하고, 자료를 `data/`에 저장해 읽을 수 있는지 확인한다.
- 사전 확인에서 준비한 Markdown 초안을 사용한다. 이미 확인된 초안이 있으면 활용한다.
- 이미지 도구에서 한글이 틀어지거나 잘못 생성될 수 있음을 알린다. ① 짧은 문구를 이미지에 함께 생성하고 결과를 확인하거나 ② 그림과 글자용 빈 공간을 먼저 만들고 편집 도구에서 한글을 따로 넣는 방법을 상황에 맞게 제안한다. 사용자의 선택을 따르며, 정확한 글자 생성이나 자동 편집을 보장하지 않는다.
- 이미지 요청문에는 목적·대상·선택한 구성·비율·분위기·배치와 필요한 문구 또는 빈 공간을 명시한다. 예: “세로 안내문으로, 밝고 친근한 분위기에 단계별 흐름을 보여 줘. 아래 한글 문구만 그대로 넣고 숫자와 단위를 바꾸지 마.” 그림만 만들 때는 글자 영역을 비워 달라고 요청한다.
- 현재 사용할 수 있는 이미지 생성·편집 도구와 권한을 확인한다. 여러 구성이나 분위기를 고르면 각각 구분해 만들고 비교를 돕는다. 도구가 없거나 결과를 저장할 수 없다면 알리고 사용할 수 있는 제작 요청문이나 편집 대안을 제안한다. 생성하지 않은 이미지를 만든 것처럼 말하지 않는다.

## 확인과 이어서 사용하기

완성 이미지에서 확인 가능한 범위의 한글·숫자·단위·배치와 가독성을 살피고, 원문과 대조할 부분을 사용자에게 알린다. 글자가 틀리면 짧게 바꾸어 재생성하거나 별도 편집으로 넣는 방법을 제안한다. 사람이 확인한 것과 AI가 확인한 것을 구분한다.

Markdown 초안과 결과는 `instructions/파일_저장_및_인계.md`에 따라 `outputs/`에 저장하고 선택한 구성과 분위기별로 구분한다. 기존 원본과 이전 결과를 보존한다. 새 자료가 오면 변경 내용을 확인하고 사용자가 원하는 결과를 다시 만든다. 자동 감시나 자동 갱신을 가정하지 않는다.
