# 문제로 꺼내 보기 (인출 연습)

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 외울 것이 많거나, 여러 번 읽었는데 막상 떠오르지 않을 때. 다시 읽는 대신 머릿속에서 꺼내 보는 연습이다.

## 진행

1. 범위와 문제 형식을 고르게 한다. 한 번에 다섯 문제 안팎으로 시작한다.

| 형식 | 맞는 때 |
| --- | --- |
| 빈칸 채우기 | 용어와 정의를 외울 때 |
| 짧게 답하기 | 개념을 한두 문장으로 말할 때 |
| 서술형 | 과정을 설명하거나 비교해야 할 때 |
| 개념 비교 표 채우기 | 비슷한 것이 여러 개일 때 |
| 용어 원어·한글 맞추기 | 원서의 용어를 익힐 때 |

문제가 **묻는 수준**도 고른다. 처음에는 기억과 이해로 시작한다.

| 수준 | 묻는 것 | 예 |
| --- | --- | --- |
| 기억 | 정의, 용어, 공식을 떠올리기 | "○○의 정의를 쓰시오" |
| 이해 | 자기 말로 풀어 설명하기 | "○○을 모르는 사람에게 설명해 보시오" |
| 적용 | 새 사례나 수치에 쓰기 | "이 상황에 ○○을 적용하면?" |
| 비교 | 비슷한 것의 차이 가르기 | "○○와 △△의 차이는?" |
| 문제 해결 | 여러 개념을 엮어 풀기 | 두 개념 이상이 필요한 문제 |

2. 문제를 내고, 사용자가 자료를 보지 않고 답한다. 한 문제씩 주고받는다. 정답은 사용자가 답하기 전에 보여 주지 않는다.
3. 답마다 맞았는지, 빠진 것이 무엇인지, 자료의 어느 위치가 근거인지 알려 준다. 틀린 부분은 사용자가 먼저 고쳐 보게 하고, 필요하면 관련된 개념을 한 줄로 이어 준다.
4. 틀리거나 망설인 문제를 표시해 `08_간격을_두고_다시_보기.md`의 복습 기록에 넣는다.
5. **수준을 조정한다.** 맞혔으면 같은 개념에서 한 단계 위의 수준(기억 → 이해 → 적용 → 비교 → 문제 해결)으로, 틀렸으면 한 단계 아래의 같은 개념 문제로 낸다. 이것은 문제 수준을 조정하는 것이지 사용자를 어떤 유형으로 나누는 것이 아니다.

## 지켜 줄 것

- 자료에 있는 내용으로만 문제를 낸다. 적용·문제 해결 문제의 새 사례를 에이전트가 만들었으면 만든 것이라고 밝히고 답의 근거 위치를 붙인다. 근거 위치를 찾지 못한 문제는 내지 않거나 `[확인 필요]`로 둔다.
- 서술형 채점은 정답 판정이 아니라 의견이다. 들어가야 할 요소 중 빠진 것과 근거 위치를 알려 준다.
- 실제 시험에 나올 문제라고 말하지 않는다. 사용자가 기출 문제나 출제 방식을 주면 그 형식에 맞출 수 있다.
- 법령, 제도, 수치처럼 바뀌는 내용은 자료의 기준 시점을 밝히고 최신 내용을 확인하게 한다.

**결과:** 문제, 사용자의 답, 근거가 붙은 채점, 다시 볼 문제 표시.

**이어서:** 시험처럼 한 번에 풀어 보려면 `11_모의고사_풀기.md`, 개념별 상태를 보려면 `06_틀린_문제_돌아보기.md`의 개념 상태 나누기로 잇는다.

**선택 확장:** 사용자가 원하면 문제와 답을 앞면·뒷면 두 칸의 표 파일(CSV)로 저장해 암기 카드 앱에 넣어 쓸 수 있다. 앱이 받는 형식은 사용자가 그 앱의 안내에서 확인한다.
