# 나란히 놓고 비교하기

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 비슷한 개념, 이론, 제도, 용어가 서로 헷갈릴 때.

## 진행

1. 헷갈리는 것 두세 개를 고른다.
2. 비교할 기준을 정한다. 정의, 쓰는 때, 조건, 대표 예처럼 서너 개면 된다. 에이전트가 제안하고 사용자가 고친다.
3. 같은 점과 다른 점을 표로 적고 근거 위치를 붙인다.
4. 개념마다 **맞는 예 하나와 아닌 예 하나**를 든다. 아닌 예가 왜 아닌지 한 줄로 적는다.
5. 표를 가리고 사용자가 차이를 한 문장으로 말해 보게 한다.

## 지켜 줄 것

- 자료마다 정의가 다르면 하나로 합치지 않고 어느 자료의 정의인지 밝힌다.
- 에이전트가 만든 예는 자료의 예와 구분한다.

**결과:** 비교표, 맞는 예와 아닌 예, 사용자가 쓴 한 문장 구분.
