# 힌트를 받으며 풀기

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 문제를 어디서부터 풀어야 할지 모르거나 중간에 막혔을 때.

## 진행

1. 문제와 사용자가 지금까지 한 풀이를 받는다. 풀이가 없으면 어디까지 생각했는지 묻는다.
2. 답이나 전체 풀이를 바로 주지 않는다. 힌트를 한 단계씩 준다. 무엇을 구하는 문제인지 → 쓸 개념이나 공식 → 첫 단계 → 다음 단계 순서다.
3. 힌트마다 사용자가 직접 한 줄을 써 보게 한다.
4. 사용자가 "풀이를 보여 줘"라고 하면 보여 준다. 그 뒤 비슷한 문제 하나를 스스로 풀어 보게 한다.

## 지켜 줄 것

- 에이전트의 계산과 풀이도 틀릴 수 있다. 검산 방법을 함께 알려 주고, 교재의 정답이 있으면 그것과 맞춰 보게 한다. 정답과 다르면 에이전트의 풀이를 다시 확인한다.
- 교재나 수업에서 쓰는 풀이 방식이 있으면 그것을 따른다.
- 제출할 과제라면 학교나 기관의 규정을 사용자가 확인하도록 알린다.

**결과:** 사용자가 쓴 풀이와, 막혔던 단계의 기록.

**이어서:** 같은 곳에서 자꾸 막히면 `06_틀린_문제_돌아보기.md`로 잇는다.
