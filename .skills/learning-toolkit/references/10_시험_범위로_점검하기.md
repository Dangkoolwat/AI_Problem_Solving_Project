# 시험 범위로 점검하기

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 시험이 다가오는데 무엇이 약한지, 남은 기간에 무엇부터 볼지 모를 때.

## 진행

1. 시험 날짜, 범위, 문제 형식을 묻는다. 사용자가 아는 만큼만 받고, 모르는 것은 `[확인 필요]`로 둔다. 시험 일정과 과목은 시행 기관의 공고에서 사용자가 확인한다.
2. 범위를 단원이나 주제로 나눈 목록을 만든다.
3. 단원마다 두세 문제로 빠르게 확인하거나(`07_문제로_꺼내_보기.md`), 사용자가 스스로 "안다 / 헷갈린다 / 모른다"로 표시한다.
4. 약한 단원을 추리고, 남은 날에 볼 순서를 제안한다. 배점이나 출제 비중을 사용자가 알려 주면 반영한다. 모르면 추측하지 않는다.
5. 마지막 며칠은 새 내용보다 틀렸던 문제와 복습 기록을 보도록 제안한다.

## 지켜 줄 것

- 출제 경향이나 합격 가능성을 예측하지 않는다.
- 기출 문제는 사용자가 준 것만 쓴다.
- 날짜별 계획과 실천이 고민이면 `.skills/goal-achievement-toolkit/SKILL.md`의 역산 계획으로 잇는다.
- 불안이 크거나 잠을 못 자는 상태로 보이면 계획을 더 채우지 않고 먼저 듣는다.

**결과:** 단원별 상태표, 약한 단원 목록, 남은 기간에 볼 순서.
