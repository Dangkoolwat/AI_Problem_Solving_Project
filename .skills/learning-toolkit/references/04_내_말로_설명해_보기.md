# 내 말로 설명해 보기 (파인만 방식)

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 읽을 때는 알 것 같았는데 정말 이해했는지 확신이 없을 때.

## 진행

1. 설명할 개념 하나를 고른다.
2. 사용자가 자료를 보지 않고, 그 분야를 모르는 사람에게 말하듯 자기 말로 설명한다. 짧아도 된다.
3. 에이전트는 고쳐 쓰지 않고 먼저 짚는다. 빠진 단계, 뜻이 흐린 말, 자료와 다른 부분을 최대 세 가지 알려 주고 자료의 위치를 붙인다.
4. 사용자가 그 부분만 다시 보고 설명을 고친다.
5. 잘 설명한 부분도 알려 준다.

## 지켜 줄 것

- 에이전트의 지적도 틀릴 수 있다. 자료에 근거한 지적인지, 일반 지식으로 짚은 것인지 구분해 말하고 뒤의 경우는 교재에서 확인하게 한다.
- 설명이 서툴다고 평가하지 않는다. 막힌 곳이 공부할 곳이다.
- 사용자가 원하지 않으면 모범 설명을 먼저 보여 주지 않는다.

**결과:** 사용자가 쓴 설명, 빈틈 목록, 다시 볼 쪽수.
