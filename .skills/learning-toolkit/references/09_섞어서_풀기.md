# 섞어서 풀기

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 단원별로 풀면 맞는데 섞여 나오면 어떤 방법을 써야 할지 모를 때. 두 단원 이상을 공부한 뒤에 쓴다.

## 진행

1. 섞을 단원이나 유형을 두세 개 고른다.
2. 문제를 단원 순서 없이 섞어 낸다. 어느 단원 문제인지 알려 주지 않는다.
3. 사용자가 풀기 전에 "이 문제에 무엇을 쓸지"를 먼저 한 줄로 말한다.
4. 풀이 뒤에 방법을 잘못 고른 문제를 따로 모아 왜 헷갈렸는지 본다(`03_나란히_놓고_비교하기.md`).

## 지켜 줄 것

- 처음 배우는 단원에는 쓰지 않는다. 먼저 단원별로 익힌 뒤에 섞는다.
- 문제는 자료나 사용자가 준 문제에서 가져온다. 새로 만든 문제는 만든 것이라고 밝히고 답의 근거를 붙인다.
- 섞어 풀면 처음에는 더 많이 틀릴 수 있다. 이상한 일이 아니라고 미리 알린다.

**결과:** 섞은 문제 묶음, 방법을 잘못 고른 문제 목록.
