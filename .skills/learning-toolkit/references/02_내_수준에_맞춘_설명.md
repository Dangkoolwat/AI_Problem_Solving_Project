# 내 수준에 맞춘 설명

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 개념 설명이 너무 어렵거나 너무 뻔할 때.

## 진행

1. 무엇을 이미 알고 무엇이 낯선지 한두 가지 묻는다. "코딩 경험이 없는 마케터"처럼 배경을 알면 설명이 정확해진다.
2. 설명 수준을 고르게 한다.

| 수준 | 설명하는 방식 |
| --- | --- |
| 처음 듣는 사람 | 쉬운 말과 일상의 비유 하나 |
| 고등학생 정도 | 익숙한 예와 원인·결과의 흐름 |
| 다른 전공의 대학생 | 원리와 쓰임, 장점과 한계 |
| 전공자·실무자 | 용어를 그대로 쓰고 근거와 예외까지 |
| 결정하는 사람 | 판단 기준, 기대되는 점, 위험, 남은 질문 |

3. 고른 수준으로 설명하고, 이해가 됐는지 묻는다. 어려우면 한 단계 내리고, 뻔하면 한 단계 올린다.

## 지켜 줄 것

- 쉽게 설명하느라 틀린 내용이 되지 않게 한다. 단순하게 줄인 부분이 있으면 "실제로는 예외가 있다"고 알린다.
- 비유는 비유라고 밝히고 어디서 어긋나는지 한 줄을 붙인다.
- 자료가 있으면 자료의 설명을 기준으로 삼고 위치를 붙인다.

**결과:** 고른 수준의 설명과, 다음에 한 단계 올려 볼 질문.
