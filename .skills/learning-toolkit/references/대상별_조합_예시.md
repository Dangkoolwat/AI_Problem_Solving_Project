# 대상별 조합 예시

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

출발점으로 쓰는 예다. 순서와 단계는 사용자의 상황에 맞게 바꾸고, 여러 날에 걸친 흐름이면 계획을 보여 준 뒤 승인받아 진행한다(`instructions/워크플로우_구성과_재사용.md`).

## 전공 원서를 공부하는 복학생·대학생

이번 주에 볼 단원 하나를 정한다.

1. 단원의 글을 마련한다(`instructions/파이썬_가상환경과_문서추출.md`). 뽑은 글이 원서와 맞는지 처음·중간·끝을 사용자가 대조한다.
2. 큰 그림부터 풀어 읽기 → 뼈대, 용어 표, 한글 요약
3. 내 말로 설명해 보기 → 핵심 개념 두세 개
4. 문제로 꺼내 보기 → 다섯 문제 안팎, 용어 원어·한글 맞추기 포함
5. 간격을 두고 다시 보기 → 틀린 것과 핵심 개념을 복습 기록에 넣기
6. 다음에 대화를 열면 복습부터 하고 새 단원으로 넘어간다.

처음에는 절 하나를 붙여 넣어 2~4번만 해 보고, 맞으면 단원 단위로 넓히도록 권한다.

## 자격증·시험을 준비하는 수험생

1. 시험 범위로 점검하기 → 약한 단원 찾기
2. 약한 단원에서 나란히 놓고 비교하기 → 헷갈리는 제도·용어 정리
3. 문제로 꺼내 보기 → 빈칸과 짧게 답하기 위주
4. 틀린 문제 돌아보기 → 틀린 이유 가르기
5. 간격을 두고 다시 보기 → 시험 날짜에 맞춰 간격 조정
6. 시험이 가까우면 섞어서 풀기, 모의고사 풀기
7. 모의고사에서 점수를 잃은 곳을 개념 상태 나누기(틀린 문제 돌아보기)로 보고, 약한 곳만 짧게 다시 보기

법령·제도·수치는 바뀐다. 문제와 답의 기준 시점을 밝히고, 최신 법령 원문과 시행 기관의 공고에서 사용자가 확인하게 한다.

## 새로 맡은 업무를 익히는 직장인

1. 내 수준에 맞춘 설명 → 낯선 용어와 개념
2. 나란히 놓고 비교하기 → 헷갈리는 용어, 지표, 절차
3. 내 말로 설명해 보기 → 동료에게 설명한다고 생각하고 써 보기
4. 필요하면 문제로 꺼내 보기 → 용어 위주로 짧게

회사 자료는 사용 권한과 회사의 AI 사용 기준을 사용자가 확인하고, 기밀은 가린다. 회사마다 용어의 뜻이 다를 수 있으므로 사내 정의가 있으면 그것을 따른다.
