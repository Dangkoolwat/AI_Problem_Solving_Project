# 틀린 문제 돌아보기 (오답 기록)

> 이 파일은 `.skills/learning-toolkit/SKILL.md`의 방법별 안내다. 공통 원칙은 SKILL.md를 먼저 읽는다.

**언제:** 문제는 푸는데 점수가 오르지 않거나, 같은 문제를 다시 틀릴 때.

## 진행

1. 틀린 문제와 사용자의 답·풀이를 받는다. 여러 개면 서너 개부터 본다.
2. 문제마다 틀린 이유를 사용자와 함께 가른다.

| 틀린 이유 | 뜻 | 다음에 할 것 |
| --- | --- | --- |
| 개념을 모름 | 필요한 내용을 몰랐다 | 그 부분을 다시 읽고 `04_내_말로_설명해_보기.md` |
| 헷갈림 | 비슷한 것과 섞였다 | `03_나란히_놓고_비교하기.md` |
| 적용을 못 함 | 아는데 문제에 쓰지 못했다 | 비슷한 문제를 `05_힌트를_받으며_풀기.md`로 |
| 문제를 잘못 읽음 | 조건이나 묻는 것을 놓쳤다 | 묻는 것에 밑줄 긋고 다시 풀기 |
| 실수 | 계산이나 옮겨 적기에서 틀렸다 | 검산 순서 정하기 |
| 시간 부족 | 알지만 시간이 모자랐다 | 시간을 재며 풀기 |

3. 이유별로 몇 개인지 세어 가장 많은 이유 하나를 고른다.
4. 그 이유에 맞는 다음 행동 하나를 정하고, 틀린 문제는 며칠 뒤 다시 풀 목록에 넣는다.

## 지켜 줄 것

- 틀린 이유는 사용자가 정한다. 에이전트는 풀이를 보고 의견을 낼 뿐이다.
- 탓하지 않는다. 틀린 문제는 공부할 곳을 알려 주는 자료다.
- 정답과 해설은 교재의 것을 기준으로 삼는다.

**결과:** 문제별 틀린 이유, 가장 많은 이유, 다시 풀 문제 목록.
