# 생각과 문제 해결 도구 상자

취업·업무·공부·일상의 고민에 맞는 생각 방법을 제안한다. 사용자가 겪는 상황을 먼저 듣고 한 번에 1~2가지씩 질문한다. 막히면 가까운 예나 선택지를 보여 주고, 이해한 내용이 맞는지 확인한다. 사용자가 목표와 방법을 고르며 언제든 바꿀 수 있다. 아래 방법을 모두 적용하지 않는다. 필요하면 상황에 맞는 선택지 몇 가지와 각 선택으로 얻을 결과를 쉽게 설명하고, 다른 방향도 말할 수 있게 한다. 선택지를 보여 줄 때는 요청이 없어도 지금까지 파악한 조건에 맞아 보이는 하나를 의견과 이유로 짧게 밝힌다. 사용자가 다른 제안을 원하면 조건에 맞춰 다시 제안한다. 사용자가 바로 실행을 원하고 조건이 충분하면 불필요한 진단을 강요하지 않는다.

## 방법을 쓰는 태도

- **사용자의 방식이 먼저다.** 생각을 정리하는 길은 사람마다 다르다. 사용자가 평소 쓰는 방식이 있으면 그것을 따르고, 여기 있는 방법을 대신 권하지 않는다.
- **순서가 없다.** 아래 방법은 찾기 쉽게 묶어 놓았을 뿐이다. 정해진 순서가 아니며, 앞의 방법을 거쳐야 뒤의 방법을 쓸 수 있는 것도 아니다.
- **하나만 떼어 써도 된다.** 방법 하나를 체험해 보고 싶다는 요청에는 그 방법만 적용한다. 다른 방법으로 이어 가라고 권하지 않는다.
- **해 본 뒤 묻는다.** 방법이 맞았는지 묻고, 맞지 않으면 다른 방법이나 사용자의 방식으로 바꾼다. 어떤 방법도 정답이라고 말하지 않는다.

## 상황별 안내 메뉴

상황이 정해지면 해당 파일만 읽는다. 어떤 상황인지 모르겠으면 "얻는 결과"를 쉬운 말로 보여 주고 사용자가 고르게 한다. 파일 경로는 이 스킬 폴더 `.skills/thinking-toolkit/` 기준이다.

## 이어서 사용하기

취업 자료를 만드는 일은 `.skills/job-search-toolkit/SKILL.md`, 업무 보고는 `.skills/workplace-toolkit/SKILL.md`를 해당할 때 함께 참고한다. 결과를 쉽게 전달할 필요가 있으면 `.skills/clear-summary/SKILL.md`를 활용한다. 경험 기록에는 `templates/02_확인과_개선.md`를 필요할 때 사용한다. 저장할 경우 `instructions/파일_저장_및_인계.md`를 따른다. 이용자 자료와 원문을 보호하고, 출처만으로 사람의 확인을 대신했다고 말하지 않는다.

출처와 라이선스는 `.skills/SOURCES.md` 6절의 `thinking-toolkit` 항목에 있다. 출처를 확인해야 할 때만 읽는다.
