# 회의·실행 목록

> 이 파일은 `.skills/workplace-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

결정된 내용과 할 일, 담당자, 기한, 미결 사항을 구분한다. 원문에 없는 사람·날짜는 `[확인 필요]`로 남긴다. 의견이나 제안을 확정된 결정처럼 쓰지 않는다.

녹음에서 시작한다면 사용 가능한 전사 도구와 자료 사용 권한을 먼저 확인한다. 제공된 전사본·메모는 분석 자료로 저장하고 읽은 범위를 밝힌다. 발언자나 내용이 불분명하면 원음 또는 사용자 확인이 필요한 부분으로 남긴다. 원하면 확인된 결정·할 일로 보고서나 공지 초안을 만들되, 초안 작성과 실제 발송을 구분한다.

회의의 목적·참석 범위, 핵심 논의, 확정된 결정, 할 일·담당·기한, 미해결 문제와 후속 행동을 실제 자료에서 확인할 수 있는 만큼 정리한다. 각 항목은 근거를 찾을 수 있도록 기록과 연결하고, 불명확한 부분은 확인 필요로 남긴다. 사용자가 요청한 보고서·실행 목록·공지 초안으로 이어갈 수 있다.
