# 여러 업무의 진행 상황 살펴보기

> 이 파일은 `.skills/workplace-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

기존 업무 기록이 있으면 먼저 읽고, 업무별 현재 상태·기다리는 답변·다음 행동·확인할 점과 관련 자료 위치를 구분해 보여 준다. 기록의 날짜와 확인 범위를 남기고 오래된 상태는 현재 사실로 단정하지 않는다. 사용자가 이어갈 업무를 선택하게 한다. 기록이 없으면 대화로 필요한 내용만 마련해 저장할 수 있다. 새 내용은 이전 기록과 결과를 지우지 않고 추가한다. 상태를 정리한다고 자동 감시·메시지 발송이 시작되는 것은 아니다.

## 내놓을 선택지

아래는 출발점이다. 상황에 맞게 2~3개로 추려 얻는 결과·필요한 것·아쉬운 점을 한 줄씩 보여 주고, 맞아 보이는 하나를 의견과 이유로 먼저 밝힌다. 사용자가 이미 방법을 정했으면 다시 고르게 하지 않는다.

| 선택지 | 얻는 결과 | 필요한 것 | 아쉬운 점 |
| --- | --- | --- | --- |
| 업무별 현황표 | 업무마다 상태·기다리는 답·다음 행동 | 업무 목록과 기억나는 상태 | 무엇부터 할지는 정해 주지 않음 |
| 지금 할 일 하나 고르기 | 지금 할 일 하나와 나중에 할 일 | 할 일과 마감 | 전체 그림은 덜 보임 |
| 업무 소통 기록 쌓기 | 날짜·출처가 있는 누적 기록 | 메일·회의 자료 | 처음 정리에 시간이 듦 |

**의견을 정하는 기준:** 전체가 안 보여 답답해하면 첫째, 당장 손을 못 대고 있으면 둘째(`.skills/thinking-toolkit/SKILL.md`), 자료가 여러 곳에 흩어져 있으면 셋째(`01_업무소통_기록.md`)를 권한다.

**결과 모습:** 현황표와 사용자가 고른 다음 업무. 기록의 날짜와 확인 범위를 함께 남긴다.
