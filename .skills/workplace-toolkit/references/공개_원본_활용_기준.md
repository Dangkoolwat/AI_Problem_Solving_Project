# 공개 원본 활용 기준과 출처

> 이 파일은 `.skills/workplace-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

공개 원본은 이 스킬 폴더의 `references/upstream/`에 전문과 라이선스를 보관한다. 해당 작업 때 아래 원본을 읽고 필요한 흐름을 활용한다. 원본의 고정 문장 길이·항목 수·이모지·자동 저장·외부 공유·연결 도구 지시는 사용자의 목적과 이 프로젝트 지침보다 우선하지 않는다.

- 회의 정리: `references/upstream/fabric/data/patterns/summarize_meeting/system.md`의 논의·결정·할 일·기한·후속 항목.
- 업무 소통과 보고: `references/upstream/anthropic-skills/internal-comms/SKILL.md`와 해당 `examples/`의 안내. 주간 진행·계획·문제는 `examples/3p-updates.md`, 일반적인 글은 `examples/general-comms.md`를 필요할 때 읽는다.
- 회의 전 준비: 구글 제미나이 기본 스킬 "Prep for Meetings"(회의 준비, 사용자 전달)의 아이디어만 참고했고 파일은 복사하지 않았다. `references/situations/11_회의_전_준비.md`에 독립 작성했다.
- 기간별 업무 보고: `references/upstream/knowledge-work-plugins/operations/skills/status-report/SKILL.md`. 같은 원본의 관련 `risk-assessment/SKILL.md`와 `CONNECTORS.md`는 해당 상황에만 참고한다.

참고한 자료: Anthropic [task-management](https://github.com/anthropics/knowledge-work-plugins/blob/main/productivity/skills/task-management/SKILL.md). 진행·대기 상태를 구분하는 아이디어를 기존 업무 기록과 원본 보존 원칙에 맞게 적용했다.
