# 자료 조사와 이해

기업·직무를 조사할 때는 이 스킬 폴더 기준 `references/upstream/career-application-advisor/skill/career-application-advisor/SKILL.md`와 그 안의 `references/company-research.md`를 읽고 필요한 조사 깊이·근거·확인 질문을 활용한다. 원본의 고정 진단과 출력 형식은 사용자의 목적에 맞춰 조정하며, 원본의 선택형 추출 스크립트는 실행 환경과 저장·개인정보 조건을 확인하기 전에는 실행하지 않는다. 원본 전체와 라이선스는 로컬에 보존한다.

사용자의 질문·목적·대상을 듣고 이미 제공된 자료와 기간을 살핀다. 조건이 불분명하면 필요한 질문을 나누어 하고, 예를 들어 공식 자료 읽기·최근 기사 비교·핵심 질문 정리처럼 가능한 방법과 결과를 쉽게 설명한다. 사용자가 하나나 여러 방법을 고르거나 다른 방향을 말할 수 있다. 명확한 요청에 불필요한 재선택을 요구하지 않는다.

1. `instructions/자료_마련과_저장.md`에 따라 제공된 파일, 공개 자료, URL, 사용 가능한 검색·브라우저·연결 도구를 살핀다. 특정 도구·사이트·최근 6개월을 필수로 정하지 않는다. 기간을 정하면 그 이유와 기준일을 밝히고 다른 기간이 필요한 자료도 구분한다.
2. 허용된 범위의 자료를 `instructions/자료_마련과_저장.md`에 따라 보관·저장하고 읽을 수 있는지 확인한 뒤 분석한다. 자료의 제목·출처·주소 또는 위치·작성일과 확인일·실제 읽은 범위를 남긴다.
3. 가능한 경우 원문·공식 자료를 살피고 자료별 사실, AI의 해석·제안, 자료 간 차이와 `[확인 필요]`를 구분한다. 회사가 직접 밝힌 내용과 외부의 평가를 섞지 않는다. 확인하지 못한 최신 상황·수치·출처를 만들지 않는다. 사용자가 중요한 내용을 직접 원문과 대조하도록 위치를 알려 준다.
4. 목적에 맞게 브리핑·비교표·면접 질문·학습 메모를 제안하거나 사용자가 지정한 결과를 만든다. 결과와 확인할 점은 `instructions/파일_저장_및_인계.md`에 따라 보관한다. 시각 자료나 글이 필요하면 확인한 내용을 Markdown 초안으로 정리하고, 사용자가 원할 때 `clear-summary`·`infographic-toolkit`이나 사용 가능한 문서 도구를 함께 활용한다.

새 자료를 이전 결과에 반영할 때 `.skills/update-workflow/SKILL.md`를 참고한다. 실제 검색·접근·콘텐츠 생성 기능은 환경에 따라 다르며, 이 스킬이 예약 수집이나 자동 검증을 수행한다고 주장하지 않는다.
