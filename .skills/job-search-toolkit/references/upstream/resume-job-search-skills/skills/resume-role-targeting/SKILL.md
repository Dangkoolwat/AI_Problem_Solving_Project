# Role Targeting

## Procedure

1. Read the complete live description when available; record source, date, location, employment model, and hard requirements.
2. Translate each responsibility from employer language into the underlying business, customer, operating, or risk problem.
3. Separate requirements into:
   - hard gate: legal, location, language, credential, schedule, or mandatory domain constraint;
   - core outcome: what the hire must deliver;
   - supporting signal: tool, method, or preferred background;
   - generic expectation: teamwork, detail, communication, or similar baseline language.
4. Map only verified evidence to the core outcomes. Label each match direct, adjacent, transferable, or missing.
5. Decide `apply`, `apply with an explicit gap`, or `skip`. A large title match does not outweigh a hard blocker.
6. Output the five highest-value role signals, the strongest evidence for each, the unresolved risks, and the tailoring brief.

## Decision rules

- Treat the description as the company's problem statement, not a keyword bag.
- For a role family, compare several postings and tailor the base resume to repeated signals; reserve per-job edits for meaningful differences.
- Do not count every listed preference as a hard requirement.
- Do not claim an industry, tool, or leadership scope merely because the posting requests it.
