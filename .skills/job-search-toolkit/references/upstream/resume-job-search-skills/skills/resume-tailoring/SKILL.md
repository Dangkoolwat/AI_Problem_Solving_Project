# Resume Tailoring

## Procedure

1. Read the role-targeting brief, evidence ledger, current resume, and output constraints.
2. Select the smallest set of recent, relevant examples that demonstrate the role's core outcomes.
3. Keep employment in reverse chronological order. Reorder bullets within a role by relevance; do not reorder employers to simulate recency.
4. Tailor:
   - headline to the target function without inflating title;
   - summary only when it adds evidence or explains a real transition;
   - skills to verified terms used by the employer;
   - bullets to foreground outcomes, ownership, judgment, and scale;
   - older work to concise support when it remains relevant.
5. Retain recent evidence over a complete career autobiography. Compress or omit irrelevant early work without creating inconsistent dates.
6. Produce a claim map from each changed line to its ledger source.
7. Hand the final draft to `resume-document-qa` when DOCX/PDF delivery is requested.

## Tailoring test

The first screenful should make the candidate's fit understandable to a rushed human reader: current function, target-relevant scope, and two or three supported outcomes. Keywords must occur in natural evidence, not in a detached list or hidden text.
