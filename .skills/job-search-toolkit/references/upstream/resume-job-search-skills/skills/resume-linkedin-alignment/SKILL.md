# LinkedIn Alignment

## Procedure

1. Choose the target role family and the search terms recruiters would plausibly use: function, level, domain, tools, and location or work model.
2. Place verified terms naturally in the headline, About, Experience, and Skills sections.
3. Make the headline and first lines communicate the candidate's function and value without slogans.
4. Rewrite duty lists as outcomes and proof. Use the same evidence ledger as the resume.
5. Reconcile employers, titles, and dates with the resume. If a title needs translation, use the same truthful clarifier in both places.
6. Proofread recent activity and profile text; remove avoidable contradictions or unprofessional content without erasing the candidate's voice.
7. Confirm recruiter messaging and relevant contact settings are enabled when the user wants inbound opportunities.

## Boundary

Discoverability is not a license for keyword repetition or an unsupported “open to” identity. The profile should be easy to find and impossible to misunderstand.
