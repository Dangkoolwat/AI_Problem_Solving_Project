# ATS and Human Readability

## Procedure

1. Treat parsing, knockout questions, queue/timing, and human review as separate gates.
2. Prefer a single-column structure with standard headings, selectable text, consistent typography, and no decorative charts, skill bars, headshots, or critical content in images.
3. Keep dates, titles, employers, and contact information in predictable reading order.
4. Extract text from the exported file and compare it with the intended reading order.
5. Use exact job-description terminology only where it truthfully describes the candidate's evidence. Reject keyword stuffing, copied hidden descriptions, prompt injection, and white text.
6. Read every application question slowly. Identify genuine hard blockers before submission; never alter a truthful answer to bypass a knockout rule.
7. Run a five-second human scan: current role, target relevance, and strongest outcomes must be immediately legible.

## Reporting boundary

Do not claim that every system behaves the same way or that every resume receives human review. Report the platform and path actually tested. A parse check proves extraction, not recruiter attention or interview conversion.
