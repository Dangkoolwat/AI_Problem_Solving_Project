# 공개 원본 활용 기준

> 이 파일은 `.skills/job-search-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

아래 원본은 축약하지 않은 로컬 참고 자료다. 각 작업에 해당하는 원본을 읽고 적용 가능한 전체 흐름을 살핀다. 원본의 Google 문서·특정 국가나 직무·고정 점수·출력 형식·발송·설치 지시는 이 프로젝트의 자료·권한·사용자 선택과 다르면 따르지 않는다. 원본에 없는 내용이나 이미 확인한 정보를 강제로 만들지 않는다. 참고 원본과 출처·라이선스, 적용 차이는 `.skills/SOURCES.md`에 있다.

아래 경로는 이 스킬 폴더 `.skills/job-search-toolkit/` 기준이다.

- 공고 URL·본문과 이력서 분석: `references/upstream/job-search-skills/job-analyzer/SKILL.md`. 채용 페이지에서 여러 공고를 찾는 경우: `references/upstream/job-search-skills/job-crawler/SKILL.md`.
- 공고 조건과 실제 경험 대조: `references/upstream/resume-job-search-skills/skills/resume-role-targeting/SKILL.md`, `references/upstream/resume-job-search-skills/skills/resume-evidence-ledger/SKILL.md`.
- 공고별 이력서와 자기소개서: `references/upstream/resume-job-search-skills/skills/resume-tailoring/SKILL.md`, `references/upstream/resume-job-search-skills/skills/resume-cover-letter/SKILL.md`. 파일 검토가 필요하면 `references/upstream/resume-job-search-skills/skills/resume-document-qa/SKILL.md`를 참고한다.
- 면접 준비: `references/upstream/resume-job-search-skills/skills/resume-interview-narratives/SKILL.md`. 필요에 따라 같은 원본의 다른 스킬도 활용할 수 있다.
