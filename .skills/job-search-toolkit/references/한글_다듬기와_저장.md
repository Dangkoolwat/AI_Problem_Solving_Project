# 한글 다듬기와 확인

> 이 파일은 `.skills/job-search-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

이력서·자기소개서 등 제출용 한국어 문장 초안에는 `.skills/humanize-korean/SKILL.md`를 읽고 적용한다. 대화 맥락에서 용도와 독자가 분명하면 불필요한 추가 질문 없이 진행한다. 상투어·번역투를 줄이되 원문의 사실·기간·수치·역할과 작성자의 목소리를 지킨다. 제공하지 않은 경험이나 성과는 추가하지 않는다. 사용자에게는 `다듬기`라고 안내한다.

다듬기 작업 전 `instructions/파일_저장_및_인계.md`를 읽고 저장 규칙을 따른다. `outputs/`의 해당 작업 폴더에 세 파일을 남기며 작업명에 `원문`, `다듬은글`, `변경기록`을 넣어 구분한다. 아래 이름은 형식을 보여 주는 예시이며 실제 작업 시각·모델명으로 바꾼다.

```text
20261113_0910_자소서_원문_GPT-6_01.md
20261113_0910_자소서_다듬은글_GPT-6_01.md
20261113_0910_자소서_변경기록_GPT-6_01.md
```

1. **다듬기 전 원문**: 다듬기 대상 문장을 작업 전 그대로 저장한다. 제공된 자료 원본은 건드리지 않는다. 개인정보가 들어 있다면 불필요한 정보의 비식별화 방법을 먼저 안내하고, 원문의 비식별 사본 사용 여부를 사용자와 정한다.
2. **다듬은 글**: 원문과 구분되는 새 파일에 저장한다. 기존 결과를 덮어쓰지 않는다.
3. **상세 변경 기록**: 변경한 문장·표현을 빠짐없이 다듬기 전과 후, 바꾼 이유를 함께 기록한다. 맞춤법·띄어쓰기만 바뀐 항목도 포함한다. 의미·수치·사실이 바뀌거나 확인이 필요한 부분과 원문 위치도 표시한다. 아무것도 바꾸지 않았다면 그 사실을 기록한다.

채팅에서는 다듬은 글과 주요 변경 예시를 최대 3개, 세 파일의 경로와 확인할 항목을 보여준다. 상세 변경 기록은 예시 3개로 제한하지 않는다. 원문 대조는 AI가 실제 확인한 범위만 밝히고 사람이 확인하지 않은 내용은 `[확인 필요]`로 둔다. 사용자가 원문·변경 기록·공고를 직접 대조해 표현과 사실을 확인하고 제출 여부를 결정한다. 확인이나 제출을 대신 완료했다고 말하지 않는다.
