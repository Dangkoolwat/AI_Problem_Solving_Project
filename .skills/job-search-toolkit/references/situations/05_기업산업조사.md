# 기업·산업 조사와 직무 연결

> 이 파일은 `.skills/job-search-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

기업과 직무를 알아보고 싶으면 `.skills/research-toolkit/SKILL.md`를 참고해 목적과 필요한 기간을 정한다. 사용자가 기간을 정하지 않으면 목적에 맞게 제안하며, 최근 6개월을 필수 조건으로 두지 않는다. 공식 자료·접근 가능한 뉴스 등 실제 확인한 자료의 출처와 날짜를 남기고 사업 내용과 경쟁사 관련 사실, 해석, 확인하지 못한 점을 구분한다. 선택한 내용을 지원동기 검토나 면접 질문으로 이어가되 회사의 의도나 지원자의 경험을 지어내지 않는다.

## 내놓을 선택지

아래는 출발점이다. 상황에 맞게 2~3개로 추려 얻는 결과·필요한 것·아쉬운 점을 한 줄씩 보여 주고, 맞아 보이는 하나를 의견과 이유로 먼저 밝힌다. 사용자가 이미 방법을 정했으면 다시 고르게 하지 않는다.

| 선택지 | 얻는 결과 | 필요한 것 | 아쉬운 점 |
| --- | --- | --- | --- |
| 회사가 직접 밝힌 자료 읽기 | 사업·제품·채용 안내에서 확인한 사실 정리 | 공식 사이트·공시·채용 페이지 접근 | 바깥의 평가는 빠짐 |
| 최근 소식 비교 | 기간을 정해 모은 기사와 서로 다른 점 | 검색 도구나 사용자가 준 기사 | 기사 품질에 따라 흔들림 |
| 면접·지원동기용 질문 만들기 | 조사 내용에서 뽑은 질문과 내 경험과의 연결 | 앞의 조사 결과 | 조사가 얕으면 질문도 얕아짐 |

**의견을 정하는 기준:** 지원동기를 써야 하면 첫째부터, 면접이 가까우면 첫째와 셋째를 이어서, 산업 흐름이 궁금하면 둘째를 권한다. 검색을 쓸 수 없으면 사용자가 자료를 주는 길을 먼저 알린다.

**결과 모습:** 출처·날짜·읽은 범위가 붙은 조사 정리와 사실·해석·`[확인 필요]` 구분.
