# 공고와 경험 연결하고 맞춤 초안 만들기

> 이 파일은 `.skills/job-search-toolkit/SKILL.md`의 상황별 안내입니다. 공통 원칙은 SKILL.md를 먼저 읽습니다.

공고에서 실제로 확인한 필수·우대 조건과 업무를 구분하고, 제공된 이력서·경험 메모의 관련 경험과 근거 위치를 나란히 보여 준다. 연결 가능한 경험, 더 확인할 내용과 준비할 점을 나누고 자료에 없다는 이유만으로 역량이 없다고 단정하지 않는다. 사용자가 원하고 비교 기준이 명확할 때만 점수를 참고용으로 제시하며 기준·가중치·누락 정보·한계를 함께 밝힌다. 채용 가능성이나 합격을 예측하는 점수로 표현하지 않는다.

공고 URL·본문이나 채용 페이지가 주어지면 원본의 공고 확보 → 조건 추출 → 이력서와 경험 대조 → 관련 경험·부족하거나 미확인인 항목 → 지원 판단에 필요한 비교라는 전체 흐름을 상황에 맞게 수행한다. 접근 가능한 공고 본문만 분석하고, 여러 공고를 살피면 공고별 근거와 날짜를 구분한다. 점수를 원하지만 기준이 정해지지 않았다면 기준과 가중치를 제안하고 사용자가 선택·수정하게 한다. 확인하지 못한 항목은 점수 근거와 별도로 표시한다. 요청에 따라 회사 조사·이력서 수정·면접 연습으로 이어간다.

사용자가 고른 경험으로 공고와 제출 형식에 맞는 이력서·자기소개서 초안을 만든다. 기존 이력서의 사실·기간·역할·수치와 사용자의 목소리를 지키고 확인되지 않은 경력이나 성과는 만들지 않는다. 새 공고를 반영할 때 기존 자료와 결과를 보존하고 `.skills/update-workflow/SKILL.md`를 참고해 이전 내용과 달라진 점을 남긴다.
