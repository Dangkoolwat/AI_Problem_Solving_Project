# 취업 고민 도구 상자

채용공고와 이력서·자기소개서·면접 준비에 필요한 방법을 상황에 맞게 고른다. 아래 순서는 필수 절차가 아니다. 필요한 방법과 예상 결과를 쉬운 말로 설명하고 사용자가 하나나 여러 가지를 선택하거나 다른 방법을 말할 수 있게 한다. 이름을 외우게 하지 않는다.

## 상황별 안내 메뉴

## 공통 원칙

- 공고·경험 자료는 `instructions/자료_마련과_저장.md`와 `instructions/파일_저장_및_인계.md`에 따라 마련·저장하고 읽을 수 있는지 확인한 뒤 분석한다. 특정 사이트나 로그인 방식을 미리 가정하지 않는다.
- 먼저 고민과 현재 준비 상태를 듣는다. 사용자가 잘 모르겠다면 아르바이트·수업·팀 활동 등 떠올리기 쉬운 예를 제시하되, 예시를 실제 경험으로 기록하지 않는다. 대화로 경험 메모를 만들 때는 사용자와 내용을 확인해 저장한다.
- 공고의 회사·직무·마감일·지원 조건은 원문에서 확인한다. 날짜와 링크 또는 문서 위치를 남기고 확인하지 못한 내용은 `[확인 필요]`로 적는다. 이름·연락처 등 불필요한 개인정보와 회사 기밀은 받지 않는다.
- 실제 역할·행동·결과를 질문해 사용자의 답을 기록한다. 숫자가 없어도 괜찮다. 경험·역량·성과를 추측해 사실로 쓰지 않으며, 실제 수행·시연 관찰·계획을 구분한다.
- 사람이 목표와 표현을 고르고 원문·경험을 직접 확인한다. AI의 출처 표시나 대조표는 사람의 검증을 대신하지 않는다.

## 취업 준비 자료 한 번에 정리하기

사용자가 전체 자료를 요청하면, 제공된 기본 정보를 바탕으로 경험 지도, 공고·경험 대조, 이력서 정리 초안, 면접 질문, 다음 할 일을 한 묶음으로 제시한다. 자기소개서 초안은 문항이나 작성 목적이 있을 때 포함한다. 자료가 없는 부분은 `[확인 필요]`로 남기고, 공고가 없으면 공고 비교를 보류한다. 질문이 필요해도 제공된 정보로 만들 수 있는 부분부터 제시한다. 경험이나 성과를 지어내지 않고 사용자가 직접 확인·선택·수정할 항목을 함께 표시한다. 문장 초안을 만든 뒤 `references/한글_다듬기와_저장.md`를 읽고 그 과정을 적용한다. 묶음 결과는 사용자가 원하면 한 파일로 저장하되, 다듬기 전후와 변경 기록은 별도 파일로 남긴다.

## 기록과 확인

필요하면 `templates/03_취업_고민_정리.md`를 읽고 해당 부분만 사용한다. 기록과 결과물은 파일 저장 안내에 따라 `outputs/`에 저장하고 양식과 자료 원본은 보존한다. 첫 결과를 보여준 뒤 확인할 점과 개선안을 제안하고 사용자가 선택한 수정만 반영한다. 사용자가 직접 확인한 항목만 확인 완료로 표시한다. 다른 한국어 문장은 사용자의 목적에 맞춰 필요한 경우 같은 스킬을 적용한다.
