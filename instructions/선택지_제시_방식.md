# 선택지 제시 방식

사용자에게 방향·방법·후속 조치를 선택지로 물을 때 읽는다. 무슨 방법을 제안할지는 `instructions/문제해결_과정.md`와 `instructions/방법_메뉴.md`를 따르고, 이 문서는 선택지를 **어떻게 보여 주고 답을 어떻게 받을지**만 정한다. 어떤 에이전트나 도구에서도 같은 방식으로 쓸 수 있게 일반 규칙으로 적는다.

## 1. 선택지를 만드는 경우와 생략하는 경우

- 선택이 정말 필요할 때만 만든다. 지시가 분명하거나 길이 하나뿐인 단순한 요청은 선택지 없이 바로 결과를 낸다.
- 이미 정한 결정과 승인받은 범위는 다시 묻지 않는다.
- 선택 질문은 한 번에 하나만 한다. 결정할 일이 여럿이면 순서대로 하나씩 묻는다.

## 2. 구성 규칙

- 선택지는 '기타'를 뺀 2~4개와, 마지막의 '기타 (직접 입력)'로 구성한다.
- 선택지마다 한 줄로 "무엇을 하는지 + 하면 어떻게 되는지"를 쓴다. 방법을 고르는 질문이면 `AGENTS.md` 4절의 ① 얻는 결과 ② 필요한 자료와 수고 ③ 아쉬운 점을 한 줄에 담는다.
- 권하는 항목이 있으면 1번에 두고 번호 뒤에 `(추천)`을 붙인다. 추천은 최대 1개이고, 이유를 한 줄로 덧붙인다. 권할 만한 것이 없으면 억지로 붙이지 않는다.
- 질문 제목 바로 뒤에 모드를 표기한다. 함께 적용할 수 있으면 `[다중 선택 가능]`, 양립할 수 없으면 `[단일 선택]`이다.

## 3. 출력 형식

```
질문 내용 [단일 선택]
1. (추천) 선택지 – 한 줄 설명
2. 선택지 – 한 줄 설명
3. 선택지 – 한 줄 설명
4. 기타 (직접 입력)

선택 방법: 1 / 추천대로면 "추천" / 기타는 "4: 원하는 내용"
```

다중 선택이면 안내에 `1, 3`처럼 여러 번호를 쓸 수 있다는 줄을 더한다. 단일 선택이면 그 줄을 뺀다.

## 4. 사용자 답 해석

| 사용자 입력 | 처리 |
| --- | --- |
| 번호 하나 (예: 1) | 그 선택지를 바로 실행한다 |
| 번호 여럿 (예: 1,3 / 1 3 / 1과 3) | 다중 선택일 때 선택지를 합쳐 바로 실행한다. 단일 선택인데 여럿이 오면 한 번만 되묻는다 |
| "추천", "네", "ㅇㅇ", "좋아" | 추천 항목을 실행한다. 추천이 없으면 되묻는다 |
| 기타 번호만 (예: 4) | 원하는 내용을 되묻는다 |
| 번호와 내용 (예: 4: ~해줘) | 내용을 반영해 바로 실행한다 |
| 그 밖의 문장, 범위 밖 번호 | 직접 입력으로 보고 말뜻대로 처리한다 |

선택을 받으면 같은 질문을 다시 확인하지 않는다.

## 5. 되돌리기 어려운 작업

삭제, 덮어쓰기, 외부 전송, 게시, 설치가 선택지에 포함되면 번호만으로 바로 실행하지 않는다. `AGENTS.md` 6절에 따라 대상과 영향을 알리고 한 번 더 확인한다.

## 6. 선택 입력 도구가 있을 때

질문과 선택지를 클릭으로 받을 수 있는 도구가 있으면 그것을 쓴다. 그런 도구는 '기타' 입력칸을 자동으로 붙이고 선택지 수에 상한이 있는 경우가 많다. 이때는 '기타'를 직접 만들지 않고, 선택지를 도구가 허용하는 수 안에서 2~4개로 맞춘다. 모드와 추천 표기, 한 줄 설명 규칙은 그대로 지킨다. 그런 도구가 없으면 3절의 텍스트 형식을 쓴다.
