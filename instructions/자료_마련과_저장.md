# 필요한 자료 마련과 저장

이 안내는 목표를 위해 자료가 필요할 때 읽는다. 특정 서비스나 도구를 필수로 정하지 않는다. 자료가 필요 없는 대화나 아이디어 요청에 인터넷 검색을 강요하지 않는다.

## 1. 필요한 것과 가능한 방법 살펴보기

- 사용자가 하려는 일을 듣고 이번 단계에 필요한 자료와 조건을 정한다. 이미 받은 답이나 자료는 다시 요구하지 않는다.
- 현재 제공된 파일과 URL, 검색, 브라우저, 연결된 앱·MCP 등 실제로 쓸 수 있는 방법을 확인한다. 특정 사이트의 접근·로그인 조건이나 도구 연결 상태를 미리 단정하지 않는다.
- 방법이 불분명하거나 사용자의 선택이 필요한 경우, 현재 가능한 방법 몇 가지와 각각으로 얻을 수 있는 자료를 쉬운 말로 설명한다. 사용자가 지정한 방법이 가능하고 조건이 충분하면 불필요한 재확인 없이 진행한다.

## 2. 자료 가져오기와 보관

- 허용된 범위에서 접근 가능한 자료를 직접 확인한다. URL을 받았다면 접근을 시도하고, 사용자가 정한 양식이 있으면 그 양식에 맞춰 자료를 정리한다. 문서·이메일·연결된 앱의 자료도 실제 제공된 범위에서 같은 원칙을 적용한다.
- 로그인이나 추가 권한이 필요하면 상황을 알리고 사용자가 직접 처리할 수 있게 돕는다. 비밀번호나 인증번호를 채팅·문서·로그에 요구하거나 기록하지 않는다. 접근할 수 없는 내용은 확인한 것처럼 적지 않는다.
- 확보한 원본은 `source/`에 보존하고, 분석에 사용할 자료는 `data/`에 저장해 읽을 수 있는지 확인한다. 사용자가 대화에 붙여 넣은 짧은 자료로 대화 안에서 답하고 끝나는 일은 저장하지 않고 바로 진행해도 된다. 결과를 파일로 남기거나 나중에 이어갈 일, 파일·링크로 받은 자료는 저장한 뒤 분석한다. 링크 주소만 저장한 것은 본문을 확보한 것이 아니다. 원문·사용자 제공 내용·AI 발췌나 정리본을 구분하고 출처, 확인 날짜와 실제로 읽은 범위를 남긴다. 자료의 일부만 가져왔으면 전체인 것처럼 다루지 않는다.
- PDF·문서 추출이나 OCR에 Python 환경이 필요하면 `instructions/파이썬_가상환경과_문서추출.md`를 따른다. 이미 사용할 수 있는 도구와 추출본을 먼저 살피고 결과를 원문과 대조한다.
- 브라우저나 연결 도구를 사용할 수 없으면 사용자가 파일·본문·메모를 제공하거나, 사용 가능한 다른 AI에서 확인한 범위를 정리해 전달하는 방법을 제안한다. 다른 AI의 답변은 원문이 아닌 중간 자료다. 저장 또는 접근이 불가능하면 알리고 해당 자료의 분석을 보류한다.

## 3. 양식과 이후 작업

- 사용자가 양식을 지정하면 그 양식을 우선 사용한다. 지정하지 않았다면 자료의 종류와 목적에 맞는 양식을 제안한다. 웹 자료는 필요할 때 `templates/05_자료_수집_기록.md`를 사용한다. 취업 경험이나 업무 소통에는 각각 해당 양식을 사용할 수 있다.
- 비어 있는 필수 정보는 `[확인 필요]`로 남기고, 없는 조건·수치·출처를 만들지 않는다. 필요한 내용과 원문의 대조는 사람이 할 수 있도록 표시한다.
- 자료를 저장하고 읽을 수 있는지 확인한 뒤 목표에 맞게 분석·작성을 이어간다. 파일명·중복 방지·결과 저장은 `instructions/파일_저장_및_인계.md`를 따른다.
