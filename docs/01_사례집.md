# 사례집: 내 고민과 가까운 것을 골라 보세요

고민 하나에 한 쪽씩 있습니다. 다 볼 필요는 없습니다. 가까운 것 하나를 골라 **첫 요청문**을 복사해 에이전트에게 말해 보세요. 처음이라면 [시작하기](00_시작하기.md)를 먼저 보세요.

## 사례는 이렇게 읽어요

| 칸 | 무엇이 있나요 |
| --- | --- |
| 이런 고민일 때 | 이 사례가 맞는 상황 |
| 첫 요청문 | 그대로 복사해 쓸 수 있는 말. `[ ]` 안만 내 상황으로 바꿉니다 |
| 에이전트가 내놓을 수 있는 방법 | 방법 2~3가지와 각각 얻는 결과, 필요한 수고, 아쉬운 점, 그리고 에이전트 의견 예시 |
| 내가 고르고 확인할 것 | 사람이 직접 해야 하는 일 |
| 얻는 결과 | 끝나면 손에 남는 것 |
| 이어서·다르게 해 보기 | 다음에 해 볼 사례나 다른 방법 |

방법 표와 에이전트 의견은 **예시**입니다. 실제로는 내 상황에 따라 다른 방법이 나올 수 있고, 마음에 들지 않으면 "다른 방법도 보여 줘"라고 하면 됩니다. 사례 속 회사, 사람, 자료는 모두 가상입니다.

## 여기에 없는 고민이라면

사례에 없어도 됩니다. 이렇게 시작하세요.

```text
요즘 [고민]이 있어. 뭐가 문제인지도 잘 모르겠어.
질문은 한 번에 한두 개만 해 주고, 작게 시작할 방법을 2~3가지 보여 줘.
네 의견도 이유와 함께 알려줘. 고르는 건 내가 할게.
```

## 어떤 사례든 끝나면

```text
이번에 내가 해결하려던 문제, 내가 직접 고르고 확인한 일, 배운 점을 정리해 줘.
이번에 쓴 방법과 다음에 써 볼 다른 방법도 한 줄씩 적어 줘.
내가 실제로 하지 않은 일은 구분하고, 내가 확인한 뒤 outputs/에 저장해 줘.
```
