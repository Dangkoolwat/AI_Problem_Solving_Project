# 시작하기

이 작업공간은 취업, 회사 일, 공부, 생활 고민을 AI 에이전트와 함께 조금씩 풀어 보는 곳입니다. 자료가 없어도, 무엇이 고민인지 몰라도 시작할 수 있습니다.

## 세 걸음으로 시작해요

1. **폴더를 엽니다.** 쓰는 AI 도구에서 이 프로젝트 폴더를 작업 폴더로 엽니다.
2. **첫 말을 건넵니다.** 아래 글을 복사해 붙여 넣으세요.

   ```text
   이 프로젝트의 AGENTS.md를 읽고 내 고민을 함께 해결해 줘.
   내 이야기를 먼저 듣고 필요한 것부터 한두 가지씩 물어봐 줘.
   방법을 2~3가지 보여 주고 네 의견도 이유와 함께 말해 줘. 고르는 건 내가 할게.
   ```

3. **고민을 말합니다.** "할 일이 많은데 뭐부터 할지 모르겠어요"처럼 있는 그대로 말하면 됩니다.

어떤 고민으로 시작할지 떠오르지 않으면 [사례집](01_사례집.md)에서 가까운 것을 하나 골라 첫 요청문을 그대로 써 보세요.

## 에이전트는 이렇게 돕습니다

- 한 번에 한두 가지만 묻습니다. 이미 말한 것은 다시 묻지 않습니다.
- 방법을 2~3가지 보여 주고, 각각 얻는 결과와 필요한 수고, 아쉬운 점을 알려 줍니다.
- "제 생각에는 이 방법이 맞아 보여요"처럼 의견을 먼저 말합니다. 그래도 고르는 사람은 나입니다.
- 고를 것이 있으면 번호 목록으로 보여 줍니다. "2"처럼 번호만 말하면 되고, 맞는 것이 없으면 마지막 "기타"에 하고 싶은 말을 직접 적으세요.
- 모르는 것은 지어내지 않고 `[확인 필요]`로 남깁니다.

에이전트가 이렇게 하지 않으면 "AGENTS.md를 읽고 따라 줘"라고 한 번 더 말해 보세요.

## 내가 할 일은 세 가지입니다

1. **고릅니다.** 목표, 방법, 고칠 점은 내가 정합니다.
2. **확인합니다.** 날짜, 숫자, 이름, 조건은 원래 자료와 직접 맞춰 봅니다. AI가 출처를 적었다고 확인이 끝난 것은 아닙니다.
3. **가립니다.** 이름, 연락처, 회사 기밀은 빼거나 가린 뒤 올립니다. [개인정보 체크리스트](reference/개인정보_체크리스트.md)를 한 번 훑어보세요.

## 폴더는 이렇게 씁니다

| 폴더 | 무엇을 두나요 |
| --- | --- |
| `source/` | 받은 그대로의 원본 (공고, 메일, PDF 등) |
| `data/` | 분석에 쓸 자료와 대화로 정리한 메모 |
| `outputs/` | 결과물과 내가 한 일의 기록 |
| `agents_logs/` | 에이전트의 작업 기록. `INDEX.md`가 작업 목록입니다 |
| `templates/` | 필요할 때 쓰는 빈 양식 |

파일을 직접 옮기지 않아도 됩니다. "원본은 source/에, 분석할 자료는 data/에 저장해 줘"라고 부탁하면 됩니다. 에이전트가 파일을 저장할 수 있는지는 쓰는 도구에 따라 다릅니다.

## 결과가 아쉬우면 이렇게 말해요

"마음에 안 들어"보다 **무엇이 어떻게 달라지면 좋은지** 말하면 정확하게 고쳐집니다.

```text
결정일은 메모에 없는 내용이야. 그 부분을 지우고 "미정"으로 바꿔 줘.
이전 결과는 그대로 두고 새 파일로 저장해 줘.
```

실제로 고쳐 가는 모습은 [고쳐 가는 과정](reference/고쳐_가는_과정.md)에서 볼 수 있습니다.

## 다음에 이어서 할 때

새 대화를 열어도 이어 갈 수 있습니다.

```text
agents_logs/INDEX.md를 보고 지난번에 하던 작업을 찾아 줘.
이어서 할지, 새 자료로 고칠지, 새로 시작할지 내가 고를 수 있게 알려줘.
```

## 막힐 때

| 이런 일이 생기면 | 이렇게 해 보세요 |
| --- | --- |
| 파일이 저장되지 않아요 | 에이전트에게 저장이 되는지 물어보세요. 안 되면 결과를 대화로 받아 직접 저장합니다 |
| 링크를 못 읽어요 | 본문을 붙여 넣거나 파일로 주세요. 방법은 [자료 마련 방법](reference/자료_마련_방법.md)에 있습니다 |
| 낯선 말이 나와요 | "쉬운 말로 다시 설명해 줘"라고 하거나 [용어 풀이](reference/용어_풀이.md)를 보세요 |
| 어떤 방법이 있는지 궁금해요 | [방법 한눈에 보기](reference/방법_한눈에_보기.md)를 보세요 |
| 모델 이름을 물어봐요 | 앱 화면에 보이는 모델 이름을 알려 주세요. 모르면 "모르겠어"라고 해도 됩니다 |
| 새 스킬·문서로 업데이트하고 싶어요 | [업데이트 가이드](00_업데이트_가이드.md)를 따라 내 작업 폴더 4개는 지키고 시스템만 최신화하세요 |

## 알아 두세요

이 작업공간만으로 자동 감시, 예약 실행, 알림이 시작되지는 않습니다. 검색, 파일 저장, 이미지 만들기가 되는지는 쓰는 도구와 설정에 따라 다릅니다.
