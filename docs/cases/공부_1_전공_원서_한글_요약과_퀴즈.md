# 공부 1. 전공 원서를 한글 요약과 퀴즈로 공부하고 싶어요

**이런 고민일 때:** 영어 원서를 읽는 데 힘을 다 쓰고 정작 내용이 남지 않을 때. 복학해서 전공 공부를 다시 시작할 때.
**주로 쓰는 도구 상자:** `learning-toolkit`

책 전체가 아니라 **이번 주에 볼 단원 하나**로 시작합니다.

## 첫 요청문

```text
전공 원서 [책 이름]의 [단원]을 공부하려고 해. 영어라서 읽는 데 시간이 많이 걸려.
한글로 핵심을 잡고, 퀴즈를 풀면서 기억에 남기고 싶어.
공부하는 방법을 2~3가지 보여 주고 네 의견도 알려줘.
용어는 영어 원어를 같이 적어 주고, 요약에는 원서 쪽수를 붙여 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 한 절만 빠르게 | 붙여 넣은 본문의 한글 요약과 퀴즈 다섯 문제 | 본문 일부를 붙여 넣기 | 기록이 남지 않고 범위가 좁음 |
| 단원 단위로 차근차근 | 요약, 용어 표, 퀴즈, 복습 기록이 파일로 쌓임 | PDF에서 글을 뽑고 확인하는 준비 | 처음 준비에 시간이 듦 |
| 시험 범위 중심 | 문제로 먼저 확인하고 틀린 곳만 요약 | 시험 범위와 단원 자료 | 전체 흐름 이해는 약함 |

> 에이전트 의견 예시: "처음이니 **한 절만 빠르게** 해 보고 감을 잡는 게 좋겠어요. 맞으면 다음부터 단원 단위로 넓혀서 기록을 쌓아 가죠."

## 단원 단위로 할 때의 흐름

1. **자료 준비:** 그 단원의 글을 PDF에서 뽑아 원본과 나눠 저장합니다. 스캔본이라 글자를 못 읽으면 에이전트가 알려 줍니다.
2. **큰 그림:** 단원의 뼈대, 용어 표(영어와 한글), 쪽수가 붙은 한글 요약을 받습니다.
3. **내 말로 설명:** 핵심 개념 두세 개를 자료를 보지 않고 설명해 보고, 빈틈을 짚어 받습니다.
4. **퀴즈:** 다섯 문제 안팎을 한 문제씩 풉니다. 답마다 근거 쪽수를 받습니다. 용어를 떠올리는 쉬운 문제로 시작해, 맞히면 적용과 비교 문제로 올라가고 틀리면 한 단계 내려갑니다.
5. **복습 기록:** 틀린 문제와 핵심 개념을 기록에 넣습니다.

```text
방금 푼 문제 중 틀린 것과 이 단원의 핵심 개념을 복습 기록에 넣어 줘.
다음에 볼 날짜도 적어 줘.
```

## 다음 날 이어 가기

```text
어제 하던 원서 공부를 이어서 하자. 먼저 복습 기록에서 오늘 다시 볼 것을 골라 문제로 내 줘.
```

에이전트는 날짜가 되어도 먼저 알려 주지 않습니다. 알림이 필요하면 달력이나 휴대폰에 직접 설정합니다.

## 내가 고르고 확인할 것

- 뽑은 글이 원서와 맞는지 처음, 중간, 끝을 직접 대조합니다. 수식, 표, 그림은 빠질 수 있습니다.
- 정의, 수식, 수치는 요약만 믿지 않고 원서의 해당 쪽에서 확인합니다.
- 한글 용어는 수업에서 쓰는 말과 다를 수 있습니다. 교수님이나 교재의 용어를 따릅니다.
- 에이전트가 만든 비유와 덧붙인 설명은 원서에 없는 내용입니다.
- 퀴즈는 실제 시험 문제를 예측한 것이 아닙니다.
- 만든 요약과 퀴즈는 내 공부용입니다. 다른 사람에게 나눠 주거나 올리는 것은 저작권과 관련될 수 있으니 직접 확인합니다.

## 얻는 결과

단원 요약, 용어 표, 푼 문제와 채점, 복습 기록.

## 이어서 해 보기

- 비슷한 개념이 헷갈리면 "이 두 개념을 나란히 비교해 줘"라고 요청합니다.
- 여러 단원을 공부한 뒤라면 "이 범위로 모의고사를 만들어 줘. 정답은 내가 답한 뒤에 알려 줘"라고 요청합니다.
- 문제와 답을 암기 카드 앱에 넣고 싶으면 "앞면·뒷면 표 파일로 저장해 줘"라고 요청합니다. 앱이 받는 형식은 앱의 안내에서 확인합니다.
