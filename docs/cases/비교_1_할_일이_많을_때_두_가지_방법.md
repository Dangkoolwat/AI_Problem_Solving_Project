# 비교 1. 할 일이 많을 때, 두 가지 방법으로 풀어 보기

같은 고민도 방법에 따라 다른 결과가 나옵니다. 아래 가상 상황 하나를 두 방법으로 풀어 보고 무엇이 다른지 직접 느껴 보세요.

## 같은 고민

```text
이번 주 할 일: 자소서 초안 쓰기(금요일 마감), 영수증 정리, 스터디 발표 준비(다음 주 수요일),
이메일 답장 두 통. 지금은 퇴근 직후라 머리가 멍해.
```

## 방법 1. 지금 할 일 하나 고르기 (`thinking-toolkit`)

```text
위 할 일 중에서 지금 내 상태에 맞는 일을 하나만 골라 줘.
나머지는 나중에 할 일로 두고 이유를 한 줄씩 알려줘.
```

나올 수 있는 결과: 지금 할 일 하나(예: 이메일 답장), 덧붙일 가벼운 일 하나, 나머지는 "나중에"와 이유. 마감이 오늘인 일이 있으면 그 일이 먼저 올라옵니다.

- 좋은 점: 바로 시작할 수 있습니다. 지친 날에 맞습니다.
- 아쉬운 점: 금요일까지 자소서를 끝낼 수 있을지는 알려 주지 않습니다.

## 방법 2. 역산 계획 (`goal-achievement-toolkit`)

```text
자소서는 금요일, 발표는 다음 주 수요일까지야.
마감에서 거꾸로 준비할 일을 나눠 줘. 내가 쓸 수 있는 시간을 먼저 물어봐 줘.
```

나올 수 있는 결과: 금요일 제출 ← 목요일 다듬기 ← 수요일 초안 ← 오늘 개요 세 줄처럼 거꾸로 나눈 단계.

- 좋은 점: 이번 주 전체가 보이고, 늦기 전에 알 수 있습니다.
- 아쉬운 점: 짜는 데 시간이 들고, 지친 날에는 계획만 보고 덮기 쉽습니다.

## 무엇이 달랐나요

| | 지금 할 일 하나 고르기 | 역산 계획 |
| --- | --- | --- |
| 묻는 것 | 지금 컨디션, 오늘 마감 | 마감일, 쓸 수 있는 시간 |
| 얻는 것 | 지금 할 일 하나 | 며칠 치 단계 |
| 맞는 때 | 막막하고 지쳤을 때 | 마감이 분명하고 여유가 조금 있을 때 |

둘을 이어 쓸 수도 있습니다. 역산 계획으로 이번 주를 나누고, 매일 저녁에는 "오늘 할 일 하나"만 고르는 식입니다.

## 해 본 뒤에

```text
방금 두 방법을 써 봤어. 내 상황에는 어느 쪽이 더 맞았는지 같이 돌아보고,
다음에 비슷한 고민이 생기면 쓸 요청문을 하나 만들어 줘.
```
