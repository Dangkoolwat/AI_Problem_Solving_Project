# 취업 1. 공고가 여러 개라 뭘 지원할지 모르겠어요

**이런 고민일 때:** 관심 공고를 내 기준으로 비교하고, 지원 전에 확인할 것을 정리하고 싶을 때.
**주로 쓰는 도구 상자:** `job-search-toolkit`, `update-workflow`

## 연습용 가상 자료

실제 공고가 아닙니다. 근무지와 마감일은 일부러 넣지 않았습니다. 내 공고로 바꿔도 됩니다.

```text
나의 기준: 고객 응대 경험을 활용하고 싶고, 엑셀을 배우며 일하고 싶다.
가상 공고 A: 한빛상점 / 고객 응대 및 주문 정리 / 엑셀 기초 활용
가상 공고 B: 다온기획 / 행사 운영 지원 / 참가자 문의와 일정 정리
```

## 첫 요청문

```text
위 내용은 연습용 가상 공고와 내 선택 기준이야.
공고를 비교하는 방법을 2~3가지 보여 주고 네 의견도 알려줘.
내가 고르면 분석할 기록을 data/에 저장하고, 결과는 outputs/에 저장해 줘.
기록에 없는 마감일과 근무 조건은 추측하지 말아 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 내 기준 비교표 | 공고별로 내 기준에 맞는 점과 확인할 점 | 기준 한두 가지만 있으면 됨 | 기준에 없는 조건은 빠질 수 있음 |
| 공고와 내 경험 대조 | 공고가 바라는 것과 연결되는 내 경험 | 경험 메모가 필요함 | 경험 정리에 시간이 듦 |
| 조건 목록 정리 | 직무·조건·마감일을 나란히 본 표 | 공고 원문이 필요함 | 무엇이 나에게 맞는지는 알려 주지 않음 |

> 에이전트 의견 예시: "기준을 이미 말씀해 주셔서 **내 기준 비교표**가 맞아 보여요. 가장 빨리 끝나고, 부족한 정보가 무엇인지도 바로 보입니다."

## 내가 고르고 확인할 것

- 두 공고의 업무가 가상 메모와 같은가요? `엑셀 기초 활용`과 `일정 정리`를 섞지 않았나요?
- 없는 조건(마감일, 근무지)이 `[확인 필요]`로 남아 있나요?
- 실제 지원이라면 마감일과 자격은 공고 원문에서 직접 확인합니다.

## 새 공고 하나 추가하기

```text
가상 공고 C: 나래서점 / 온라인 주문 정리 및 고객 문의 / 엑셀 기초 활용
```

```text
새 가상 공고 C를 기존 자료와 구분해 data/에 저장해 줘.
이전 비교표는 그대로 두고 세 공고를 비교한 새 결과를 만들어 줘.
새로 추가된 내용과 내가 다시 확인할 점도 알려줘.
```

C가 추가됐는지, A와 B의 내용이 그대로인지 확인하세요.

## 얻는 결과

공고 비교표 두 개(처음 것과 새 공고를 넣은 것)와 달라진 점 정리.
