# 생활 3. 이사나 큰 지출을 앞두고 결정이 어려워요

**이런 고민일 때:** 자취방 계약, 지원금 신청, 큰 물건 구입처럼 되돌리기 어려운 선택을 앞두고 있을 때.
**주로 쓰는 도구 상자:** `thinking-toolkit`, `evidence-check`, `research-toolkit`

## 첫 요청문

```text
[결정할 일]을 앞두고 있어. 선택지는 [A]와 [B]야.
내가 중요하게 생각하는 기준을 먼저 물어봐 줘.
살펴보는 방법을 2~3가지 보여 주고 네 의견도 알려줘.
내가 준 숫자와 네가 예로 든 숫자는 구분해 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 내 기준 비교표 | 선택지별 기대, 제약, 포기할 것 | 기준 두세 가지 | 기준 밖의 위험은 안 보임 |
| 여러 관점으로 점검 | 현실 점검·걱정·몇 년 뒤의 나 등 관점별 입장과 핵심 조건 | 선택지가 정해져 있어야 함 | 관점은 AI가 가정한 것임 |
| 확인 목록 만들기 | 계약 전이나 신청 전에 내가 확인할 항목 | 공고나 계약 메모 | 결정 자체를 도와주지는 않음 |

> 에이전트 의견 예시: "계약이 다음 주라고 하셔서 **확인 목록 만들기**를 먼저 권해요. 비교는 이미 많이 하신 것 같고, 지금은 놓친 확인이 더 위험합니다."

## 내가 고르고 확인할 것

- 지원 자격, 금액, 기한은 공고 원문에서 직접 확인합니다. 공고마다 날짜와 기준이 다를 수 있습니다.
- 계약서 조항이 무슨 뜻인지, 법적으로 어떤지는 에이전트가 확정할 수 없습니다. 필요하면 전문가나 공공 상담 창구에 확인합니다.
- 에이전트의 의견은 "지금 정보로는" 붙은 의견입니다. 정보가 바뀌면 다시 봅니다.

## 얻는 결과

기준별 비교표나 확인 목록, 결정에 필요한 핵심 조건 한두 개.

## 이어서 해 보기

- 지원금 공고가 여러 개면 "세 공고의 조건을 내 상황과 대조해 줘"라고 요청합니다 (`evidence-check`).
- 결정한 뒤에는 "해 보면서 확인할 점만 정리해 줘"라고 바꿔 요청합니다.
