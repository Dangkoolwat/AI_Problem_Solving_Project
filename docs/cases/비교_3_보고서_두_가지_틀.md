# 비교 3. 같은 메모로 보고서 쓰기, 두 가지 틀로 풀어 보기

같은 회의 메모도 어떤 틀로 쓰느냐에 따라 읽는 사람이 받는 인상이 달라집니다. [직장 1](직장_1_회의_메모_보고와_갱신.md)의 가상 메모를 그대로 씁니다.

## 같은 자료

```text
업무: 청년 대상 소규모 행사 준비
회의 메모 1: 장소 후보를 알아보기로 했다. 담당자와 결정일은 아직 정하지 않았다.
회의 메모 2: 홍보 문구 초안이 필요하다. 참가 신청 방법은 논의 중이다.
```

## 틀 1. 육하원칙

```text
이 메모를 육하원칙으로 정리해 줘. 메모에 없는 칸은 [확인 필요]로 남겨 줘.
```

나올 수 있는 결과:

| 칸 | 내용 |
| --- | --- |
| 무엇을 | 장소 후보 알아보기, 홍보 문구 초안 |
| 누가 | `[확인 필요]` |
| 언제 | `[확인 필요]` |
| 어떻게 | 참가 신청 방법은 논의 중 |

- 좋은 점: 무엇이 비어 있는지 한눈에 보입니다.
- 아쉬운 점: 그래서 무엇을 해 달라는 것인지는 드러나지 않습니다.

## 틀 2. 왜·무엇을·어떻게·어떤 조건 (Why–What–How–If)

```text
이 메모로 팀장에게 결정을 부탁하는 보고를 쓰고 싶어.
왜·무엇을·어떻게·어떤 조건 틀로 써 줘. 없는 내용은 지어내지 말아 줘.
```

나올 수 있는 결과:

- 왜: 행사 준비에서 담당과 결정일이 비어 있어 다음 일을 시작하기 어렵습니다.
- 무엇을: 장소 후보 조사와 홍보 문구 초안이 필요합니다.
- 어떻게: 담당이 정해지면 후보 조사부터 시작합니다. 일정은 `[확인 필요]`.
- 어떤 조건: 장소 담당자와 결정일을 정해 주셔야 합니다.

- 좋은 점: 읽는 사람이 무엇을 정해 줘야 하는지 알 수 있습니다.
- 아쉬운 점: 단순히 알리기만 할 때는 무겁습니다.

## 무엇이 달랐나요

| | 육하원칙 | 왜·무엇을·어떻게·어떤 조건 |
| --- | --- | --- |
| 목적 | 사실을 빠짐없이 정리 | 결정이나 행동을 부탁 |
| 읽는 사람이 얻는 것 | 지금 상태 | 자기가 할 일 |
| 맞는 때 | 현황 공유, 기록 | 결정 요청, 문제 보고 |

## 내가 확인할 것

두 결과 모두에서 담당자와 날짜가 지어지지 않았는지 메모와 한 줄씩 맞춰 봅니다. 틀이 달라져도 사실은 같아야 합니다.

## 해 본 뒤에

```text
두 틀로 써 봤어. 내 팀장에게는 어느 쪽이 맞을지 네 의견을 이유와 함께 알려줘.
```
