# 공부 3. 문제를 풀어도 왜 틀리는지 모르겠어요

**이런 고민일 때:** 공부는 하는데 점수가 그대로이거나, 같은 문제를 또 틀릴 때.
**주로 쓰는 도구 상자:** `learning-toolkit`, `thinking-toolkit`

## 첫 요청문

```text
[과목] 문제를 계속 틀려. 틀린 문제와 내 풀이를 줄게.
답을 바로 알려 주지 말고, 왜 틀렸는지 같이 살펴봐 줘.
살펴보는 방법을 2~3가지 보여 주고 네 의견도 알려줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 틀린 문제 돌아보기 | 문제별 틀린 이유와 가장 많은 이유 하나 | 틀린 문제 서너 개와 내 풀이 | 풀이를 남겨 두지 않았으면 하기 어려움 |
| 힌트를 받으며 다시 풀기 | 한 단계씩 힌트를 받아 내가 쓴 풀이 | 문제 하나와 시간 | 한 번에 한 문제만 다룸 |
| 막힌 단계 찾기 | 공부 과정 중 가장 막힌 단계 | 지금까지의 공부 방식 | 문제 하나하나는 다루지 않음 |

틀린 이유는 보통 이 여섯 가지 중 하나입니다. 개념을 모름, 비슷한 것과 헷갈림, 아는데 적용을 못 함, 문제를 잘못 읽음, 실수, 시간 부족.

> 에이전트 의견 예시: "풀이를 가지고 계시니 **틀린 문제 돌아보기**가 맞아 보여요. 네 문제만 봐도 어떤 이유가 많은지 드러납니다."

## 내가 고르고 확인할 것

- 틀린 이유는 내가 정합니다. 에이전트의 말은 내 풀이를 본 의견입니다.
- 에이전트의 풀이와 계산도 틀릴 수 있습니다. 교재의 정답과 해설을 기준으로 삼고, 다르면 에이전트에게 다시 확인시킵니다.
- 제출할 과제라면 도움을 받아도 되는지 학교나 기관의 규정을 확인합니다.

## 얻는 결과

문제별 틀린 이유, 가장 많은 이유에 맞는 다음 행동 하나, 며칠 뒤 다시 풀 문제 목록.
