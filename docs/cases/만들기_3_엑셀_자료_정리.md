# 만들기 3. 엑셀 자료가 지저분해서 손을 못 대겠어요

**이런 고민일 때:** 엑셀이나 CSV 파일에서 필요한 것만 뽑거나, 표를 정리해 비교하고 싶을 때.
**주로 쓰는 도구 상자:** `data-toolkit`, `evidence-check`

## 연습용 가상 자료

아래 내용을 붙여 넣어 연습할 수 있습니다. 실제 자료가 아닙니다.

```text
날짜,항목,금액,메모
2026-10-03,점심,9000,
2026-10-03,점심,9000,
2026-10-05,교통,,카드
2026-10-07,구독,13900,영상
10/9,점심,8500,
```

## 첫 요청문

```text
위 표 자료를 정리하고 싶어. 먼저 어떤 열이 있고 어디가 이상한지 살펴봐 줘.
그다음 할 수 있는 정리 방법을 2~3가지 보여 주고 네 의견도 알려줘.
원본은 그대로 두고 정리한 결과는 새 파일로 저장해 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 자료 살펴보기 | 열의 뜻, 빈 값, 중복, 형식이 다른 곳 목록 | 파일만 있으면 됨 | 정리된 표는 아직 없음 |
| 필요한 것만 골라 정리 | 조건에 맞는 행과 열만 남긴 새 표 | 무엇이 필요한지 정해야 함 | 빠진 행을 놓칠 수 있음 |
| 묶어서 합계 보기 | 항목별·기간별 합계 표 | 금액과 날짜가 깨끗해야 함 | 빈 값이 있으면 합계가 틀어짐 |

> 에이전트 의견 예시: "빈 금액과 겹친 줄이 보여서 **자료 살펴보기**를 먼저 해야 해요. 그걸 어떻게 처리할지 정해 주시면 합계는 금방 낼 수 있습니다."

## 내가 고르고 확인할 것

- 겹친 줄이 정말 중복인지, 같은 날 두 번 쓴 것인지는 내가 압니다. 에이전트가 마음대로 지우지 않게 합니다.
- 빈 금액을 0이나 다른 숫자로 채우지 않았나요? `[확인 필요]`로 남아 있어야 합니다.
- 합계가 맞는지 몇 줄을 골라 원본과 직접 맞춰 봅니다. 기간과 단위도 봅니다.
- 엑셀의 수식과 서식을 그대로 다룰 수 있는지는 쓰는 도구에 따라 다릅니다.

## 얻는 결과

이상한 곳 목록, 정리된 새 표, 항목별 합계.

## 이어서 해 보기

- 다음 달 자료가 생기면 "지난 결과는 그대로 두고 새 자료를 반영해 줘. 달라진 점을 먼저 알려줘"라고 요청합니다.
- 보고서의 숫자와 표의 숫자가 다르면 "두 자료의 숫자를 대조해 줘"라고 요청합니다.
