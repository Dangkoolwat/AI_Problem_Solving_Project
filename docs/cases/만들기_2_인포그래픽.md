# 만들기 2. 내용을 그림 한 장으로 보여 주고 싶어요

**이런 고민일 때:** 보고 내용, 공부한 것, 일정, 선택지의 차이를 그림과 짧은 글로 전하고 싶을 때.
**주로 쓰는 도구 상자:** `infographic-toolkit`, `clear-summary`

## 첫 요청문

```text
이 자료를 [대상]에게 [목적]으로 한 장에 보여 주고 싶어.
먼저 쓸 자료와 글 초안이 있는지 물어봐 줘. 없으면 같이 만들자.
어울리는 구성을 2~3가지 보여 주고 네 의견도 알려줘.
한글을 그림에 같이 넣는 방법과 나중에 넣는 방법도 설명해 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 구성 | 얻는 결과 | 어울리는 내용 | 아쉬운 점 |
| --- | --- | --- | --- |
| 핵심 요약형 | 제목과 핵심 몇 가지 | 긴 내용의 요점 | 순서나 흐름은 안 보임 |
| 단계 안내형 | 순서대로 이어지는 설명 | 절차, 방법 | 단계가 많으면 빽빽해짐 |
| 비교형 | 같은 기준으로 나란히 놓은 그림 | 선택지, 전과 후 | 기준이 다르면 쓰기 어려움 |
| 숫자 강조형 | 핵심 숫자와 짧은 설명 | 확인된 수치 | 숫자가 틀리면 전체가 틀림 |
| 타임라인형 | 날짜순 배치 | 일정, 변화 | 날짜가 없으면 못 씀 |

분위기도 따로 고를 수 있습니다. 깔끔한 업무 보고, 밝고 친근한 그림, 차분하고 따뜻한 느낌, 선명한 포스터, 손그림 노트, 사진 배경의 감성형 중에서 고르거나 직접 설명해도 됩니다.

> 에이전트 의견 예시: "순서를 알려 주는 내용이라 **단계 안내형**이 맞아 보여요. 문구가 정확해야 하니 그림을 먼저 만들고 한글은 나중에 넣는 쪽을 권합니다."

## 내가 고르고 확인할 것

- 그림을 만들기 전에 제목, 문구, 숫자, 출처가 적힌 글 초안을 먼저 확인합니다.
- 그림 속 한글은 깨지거나 틀릴 수 있습니다. 글자를 한 자씩 읽어 봅니다.
- 자료에 없는 숫자나 내용이 더해지지 않았나요? 날짜와 단위도 봅니다.
- 그림을 만들 수 있는지는 쓰는 도구에 따라 다릅니다. 안 되면 구성안과 요청문까지만 받습니다.

## 만들기

```text
[고른 구성]으로 만들고 싶어. [쓸 곳]에 맞는 크기와 [원하는 분위기]로 해 줘.
먼저 제목, 문구, 숫자, 출처를 글 초안으로 정리해 data/에 저장해 줘.
내가 확인한 뒤에 그림을 만들어 줘.
중요한 한글은 [그림에 같이 넣기 / 빈 자리를 두고 나중에 넣기]로 해 줘.
```

## 얻는 결과

확인한 글 초안과 인포그래픽 그림(또는 구성안).
