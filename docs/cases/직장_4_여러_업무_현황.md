# 직장 4. 맡은 일이 여러 개라 어디까지 했는지 모르겠어요

**이런 고민일 때:** 여러 업무가 동시에 돌아가서 각각의 상태와 다음 할 일을 한눈에 보고 싶을 때.
**주로 쓰는 도구 상자:** `workplace-toolkit`, `thinking-toolkit`

## 첫 요청문

```text
진행 중인 일이 여러 개 있어. 어떤 업무가 있는지 한두 가지씩 물어봐 줘.
정리하는 방법을 2~3가지 보여 주고 네 의견도 알려줘.
서로 다른 업무를 섞거나 확인하지 않은 상태를 단정하지 말아 줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 업무별 현황표 | 업무마다 지금 상태, 기다리는 답, 다음 행동 | 업무 목록과 기억나는 상태 | 무엇부터 할지는 정해 주지 않음 |
| 지금 할 일 하나 고르기 | 지금 할 일 하나와 나중에 할 일 | 할 일 두세 가지와 마감 | 전체 그림은 덜 보임 |
| 업무 소통 기록 쌓기 | 날짜와 출처가 있는 누적 기록 | 메일·회의 자료 | 처음 정리에 시간이 듦 |

> 에이전트 의견 예시: "전체가 안 보여서 답답하신 것 같아 **업무별 현황표**부터 만드는 게 좋겠어요. 표가 나오면 그중 지금 할 일 하나를 같이 고르면 됩니다."

## 내가 고르고 확인할 것

- 각 업무의 상태가 지금과 맞나요? 오래된 인계 내용은 다시 확인이 필요합니다.
- "기다리는 답"의 상대와 날짜를 에이전트가 지어내지 않았나요?
- 표를 만들었다고 자동으로 감시되거나 알림이 오지는 않습니다.

## 하나를 골라 이어 가기

```text
지금 보여 준 업무 중 [업무 이름]부터 이어서 도와줘.
끝난 일과 남은 일을 구분하고, 다음에 할 수 있는 방법과 네 의견을 알려줘.
새로 확인한 내용은 기존 기록을 지우지 말고 추가해 줘.
```

## 얻는 결과

업무별 현황표와 지금 할 일 하나.
