# 취업 3. 면접이 불안해요

**이런 고민일 때:** 어떤 질문이 나올지 모르겠고, 답을 말로 꺼내는 연습이 필요할 때.
**주로 쓰는 도구 상자:** `job-search-toolkit`, `thinking-toolkit`

## 첫 요청문

```text
면접 연습을 하고 싶어. 지원하려는 직무와 내가 말할 수 있는 경험을 먼저 물어봐 줘.
연습 방법을 2~3가지 보여 주고 네 의견도 알려줘.
질문은 한 번에 하나씩 하고, 내 답이 끝나면 더 구체적으로 말하면 좋을 점을 쉽게 알려줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 예상 질문 목록 만들기 | 공고와 경험에서 나올 만한 질문 | 공고나 직무 정보 | 답하는 연습은 따로 해야 함 |
| 한 문제씩 묻고 답하기 | 실제로 답해 보고 받는 짧은 조언 | 시간과 집중 | 한 번에 많은 질문을 다루지 못함 |
| 면접관 입장에서 내 답 보기 | 면접관이 더 궁금해할 점 | 써 둔 답이 있어야 함 | 실제 면접관의 생각은 아님 |

> 에이전트 의견 예시: "면접까지 시간이 있고 답을 말해 본 적이 없으시니 **한 문제씩 묻고 답하기**가 좋아 보여요. 세 문제만 해도 어디가 막히는지 보입니다."

## 내가 고르고 확인할 것

- 에이전트의 조언이 내 경험의 사실을 바꾸지 않았나요? 말하지 않은 성과가 답에 들어가지 않았나요?
- 예상 질문은 가능성일 뿐입니다. 실제 면접 질문과 다를 수 있습니다.
- 회사와 직무 정보는 공고 원문과 회사가 직접 밝힌 자료에서 확인합니다.

## 얻는 결과

예상 질문, 내가 한 답과 고칠 점, 다음에 연습할 것.

## 이어서 해 보기

- 답이 막히는 질문은 "이 질문에 쓸 경험을 스타(STAR)로 정리해 줘"라고 요청합니다.
- 연습한 내용을 남기려면 "내가 실제로 답한 내용과 고칠 점을 outputs/에 저장해 줘"라고 합니다.
