# 생활 6. 냉장고 재료로 저녁을 차리고 싶어요

**이런 고민일 때:** 있는 재료로 무엇을 만들지, 식사 시간에 맞추려면 언제 무엇을 해야 할지 알고 싶을 때.
**주로 쓰는 도구 상자:** `research-toolkit`, `update-workflow`, 웹 도구 제작 안내

## 연습용 가상 자료

```text
집에 김치, 두부, 돼지고기, 대파가 있어.
가족 네 사람이 저녁 7시에 먹을 김치찌개를 만들고 싶어.
```

사진을 읽을 수 있는 에이전트라면 냉장고 사진을 보여 줘도 됩니다. 그때는 "확실히 보이는 것과 알기 어려운 것을 구분해 줘. 메뉴 추천 전에 내가 재료 목록을 확인할게"라고 덧붙이세요.

## 첫 요청문

```text
위 재료와 조건으로 저녁을 준비하고 싶어. 이미 말한 메뉴와 인원은 다시 묻지 말아 줘.
진행 방법을 2~3가지 보여 주고 네 의견도 알려줘.
레시피는 실제로 확인한 자료만 쓰고 출처를 알려줘.
```

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 레시피 두세 개 비교 | 재료·분량·시간이 다른 점을 본 표 | 레시피 링크나 검색 | 시간이 조금 더 걸림 |
| 레시피 하나로 바로 계획 | 4인분 분량과 조리 순서 | 레시피 하나 | 다른 방식은 못 봄 |
| 식사 시각에서 거꾸로 시간표 | 준비부터 완성까지 시간표 | 정해진 레시피 | 실제 시간은 달라질 수 있음 |

> 에이전트 의견 예시: "메뉴가 정해져 있으니 **레시피 하나로 바로 계획**을 세우고, 그걸로 시간표까지 만드는 게 좋겠어요. 비교는 다음에 다른 맛을 내고 싶을 때 해도 됩니다."

## 내가 고르고 확인할 것

- 링크를 열어 재료와 분량이 표와 맞는지 봅니다. 에이전트가 못 읽은 레시피는 읽은 것처럼 쓰면 안 됩니다.
- 원래 레시피의 인분과 4인분으로 바꾼 분량이 구분되어 있나요?
- 알레르기, 익힘, 보관은 직접 확인합니다. 저염·저당 제안은 개인 맞춤 식단이 아닙니다. 질환이 있다면 의사나 영양사에게 확인합니다.

## 새 조건을 넣어 고치기

```text
새 조건은 "식사 시간이 30분 늦어졌어"야. 기존 결과는 그대로 두고,
시간표에서 바꿀 점을 먼저 알려줘. 내가 고른 변경을 반영한 새 결과를 저장해 줘.
```

## 얻는 결과

4인분 레시피와 조리 시간표, 새 조건을 반영한 시간표.

## 이어서 해 보기

시간표를 확인한 뒤 "이 시간표로 쓸 간단한 웹 타이머를 만들어 줘. 시작·일시정지·초기화 버튼을 크게 넣어 줘"라고 요청할 수 있습니다. 파일을 열어 버튼을 직접 눌러 보고, 음식의 익힘은 타이머만으로 판단하지 않습니다.
