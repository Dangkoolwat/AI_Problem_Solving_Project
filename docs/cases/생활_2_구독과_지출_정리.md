# 생활 2. 돈이 어디로 새는지 모르겠어요

**이런 고민일 때:** 구독 서비스와 고정 지출을 한 번 정리하고 줄일 것을 고르고 싶을 때.
**주로 쓰는 도구 상자:** `thinking-toolkit`, `data-toolkit` (돈 관리 전용 도구 상자는 없습니다)

## 첫 요청문

```text
매달 나가는 구독과 고정 지출을 정리하고 싶어. 목록은 아래에 적을게.
내 기준을 먼저 물어봐 줘. 정리 방법을 2~3가지 보여 주고 네 의견도 알려줘.
내가 적지 않은 금액은 지어내지 말아 줘. 카드 번호 같은 건 안 줄게.
```

연습용 가상 목록: `영상 구독 A 13,900원 / 음악 구독 B 10,900원 / 운동 앱 C 9,900원 / 클라우드 D 2,900원`

## 에이전트가 내놓을 수 있는 방법

| 방법 | 얻는 결과 | 필요한 것과 수고 | 아쉬운 점 |
| --- | --- | --- | --- |
| 세 칸으로 나누기 | 꼭 필요한 것, 줄일 수 있는 것, 더 고민할 것 | 지출 목록과 내 기준 | 금액 합계는 덜 보임 |
| 표로 합계 보기 | 항목별 금액과 월·연 합계 | 금액이 적힌 목록 | 무엇을 줄일지는 알려 주지 않음 |
| 지난달과 비교 | 늘거나 준 항목 | 두 달 치 목록 | 자료가 두 벌 필요함 |

> 에이전트 의견 예시: "항목이 많지 않아서 **세 칸으로 나누기**가 맞아 보여요. 합계는 표 아래 한 줄로 같이 적어 드릴게요."

## 내가 고르고 확인할 것

- 합계를 직접 한 번 더해 봅니다. 금액과 단위(월, 연)가 맞나요?
- 해지 조건과 위약금은 각 서비스의 안내에서 직접 확인합니다.
- 투자나 대출 같은 결정은 에이전트의 의견만으로 정하지 않습니다.

## 얻는 결과

내 기준으로 나눈 지출 표와 이번 달에 줄일 것 한 가지.
