# 용어 풀이

낯선 말이 나오면 여기서 찾아보세요. 외울 필요는 없습니다. 에이전트에게 "쉬운 말로 다시 설명해 줘"라고 해도 됩니다.

## 작업공간 말

| 말 | 쉬운 뜻 |
| --- | --- |
| **에이전트** | 말만 하는 AI가 아니라 파일을 읽고 쓰고 자료를 찾는 일을 함께 해 주는 AI |
| **요청문(프롬프트)** | AI에게 하는 부탁의 글. 목표와 원하는 결과, 지켜 줬으면 하는 것을 적으면 좋아요 |
| **스킬(도구 상자)** | 상황별로 쓸 수 있는 방법을 모아 둔 안내서. `.skills/` 폴더에 있어요 |
| **워크플로우** | 목표를 이루려고 자료 준비 → 작업 → 확인을 이어 놓은 순서 |
| **원본 / 중간 자료** | 원본은 내가 받은 그대로의 자료. 중간 자료는 AI나 내가 읽기 쉽게 정리한 것 (원본과 구분해요) |
| **비식별화** | 이름·연락처처럼 누구인지 알 수 있는 정보를 지우거나 가리는 것 |
| **`[확인 필요]`** | 아직 확인하지 못한 내용 표시. 지어내지 않고 남겨 둔 칸이에요 |
| **색인(`INDEX.md`)** | 어떤 작업이 있었는지 한 줄씩 적은 목록. 새 대화에서 이어갈 작업을 찾을 때 써요 |
| **갱신** | 새 자료를 넣어 이전 결과를 고쳐 다시 만드는 것 (이전 결과는 그대로 남겨요) |
| **커넥터 / MCP** | AI가 내 폴더나 메신저 같은 앱에 연결해 자료를 가져오게 해 주는 연결 장치 |
| **OCR** | 사진이나 스캔한 문서 속 글자를 글로 읽어 내는 기술 |
| **토큰** | AI가 글을 읽고 쓰는 양의 단위. 길수록 사용량이 늘어요 |

## 방법 이름

| 말 | 쉬운 뜻 |
| --- | --- |
| **4R** | 경험을 역할(Roles)·관계(Relationships)·자원(Resources)·결과(Results) 네 가지로 떠올려 보는 틀 |
| **스타 (STAR)** | 상황(Situation)·과제(Task)·행동(Action)·결과(Result) 순서로 경험을 말하는 틀 |
| **스왓 (SWOT)** | 강점·약점·기회·위협을 나눠서 돌아보는 틀 |
| **육하원칙** | 누가·언제·어디서·무엇을·어떻게·왜 |
| **왜·무엇을·어떻게·어떤 조건 (Why–What–How–If)** | 왜 보고하는지, 핵심이 뭔지, 어떻게 진행하는지, 어떤 조건이나 결정이 필요한지로 정리하는 보고 틀 |
| **막힌 단계 찾기** | 하는 일을 단계로 나눠 가장 막힌 곳 하나를 찾는 방법 |
| **파레토 관점** | 적은 수의 일이 결과의 큰 부분을 좌우한다고 보고, 영향이 큰 것부터 고르는 생각. 80과 20은 재어 본 숫자가 아니라 비유예요 |
| **스캠퍼 (SCAMPER)** | 가진 아이디어를 바꾸기·합치기·가져오기·고치기·다르게 쓰기·빼기·뒤집기로 넓혀 보는 방법 |
| **그다음 영향** | 선택한 뒤에 이어서 생길 수 있는 일을 한두 단계 더 따라가 보는 것 |
| **사전 점검** | 계획이 어려워졌다고 가정해 놓친 위험을 미리 찾아보는 방법 |
| **만다라트 (Mandal-Art)** | 가운데 생각에서 출발해 관련 목표나 아이디어를 칸에 펼쳐 보는 방법 |
| **목표와 핵심 결과 (OKR)** | 이루고 싶은 방향과 달라졌는지 확인할 핵심 결과를 함께 정하는 방법 |
| **스마트 목표 (SMART)** | 목표의 구체성·확인 가능성·실현 가능성·관련성·기한을 살펴보는 기준 |
| **배우는 목표 (Learning Goal)** | 합격·성과 같은 결과 대신 알아보거나 익히고 싶은 것을 목표로 삼는 방법 |
| **우프 (WOOP)** | 바람·기대 결과·내적 장애물·대응 계획을 차례로 생각하는 방법 |
| **내적 장애물** | 바라는 일을 막는 내 안의 반응. 망설임·불안·미루고 싶은 마음 등 |
| **해빗 스태킹 (Habit Stacking)** | 이미 하는 행동 뒤에 새로운 작은 행동을 붙이는 방법 |
| **유혹 묶기 (Temptation Bundling)** | 미루는 일을 할 때만 좋아하는 즐길 거리를 함께하는 방법 |
| **그로우 (GROW)** | 바라는 것·현재 상황·선택지·다음 행동을 대화로 살펴보는 방법 |
| **역산 계획 (Backward Planning)** | 원하는 결과에서 거꾸로 필요한 준비를 나누는 방법 |
| **실행 의도 (Implementation Intention, If–Then)** | 어떤 상황에서 어떤 행동을 할지 미리 연결하는 계획 |
| **새 출발 효과 (Fresh Start Effect)** | 새 주·월·생일처럼 구분이 되는 날을 시작하는 계기로 삼는 방법 |
| **돌아보기와 조정** | 실제로 해 본 일과 어려움을 살펴 목표나 방법을 바꾸는 과정 |

## 공부 방법 이름

| 말 | 쉬운 뜻 |
| --- | --- |
| **파인만 방식** | 배운 것을 모르는 사람에게 말하듯 내 말로 설명해 보고 빈틈을 찾는 방법 |
| **인출 연습** | 다시 읽는 대신 문제를 풀며 머릿속에서 꺼내 보는 연습 |
| **간격 반복** | 한 번에 몰아 보지 않고 날짜를 벌려 가며 다시 보는 방법 |
| **섞어서 풀기** | 여러 단원의 문제를 순서 없이 섞어 푸는 방법 |
| **오답 기록** | 틀린 문제와 틀린 이유를 적어 두고 다시 푸는 기록 |
| **개념 상태 나누기** | 이번에 낸 답을 모아 개념마다 이해함, 부분적으로 이해함, 잘못 이해함, 계속 잊음, 연습이 필요함으로 나누는 방법 |
| **시험 지도** | 시험 범위를 단원, 핵심 개념, 정의, 공식, 과정으로 정리한 목록. 기초와 심화를 나눕니다 |
| **모의고사 풀기** | 공부한 범위로 시험처럼 문제를 풀고 점수를 잃은 주제를 찾는 연습 |
