# 자료 마련 방법

자료가 없어도 시작할 수 있습니다. 자료가 필요해지면 아래 네 가지 길 중 되는 것부터 쓰면 됩니다. 어떤 길이 맞는지 모르겠다면 이렇게 물어보세요.

```text
내가 하려는 일에 어떤 자료가 필요한지와 지금 쓸 수 있는 방법을 알려줘.
이미 준 자료는 다시 요구하지 말고, 되는 방법과 막힌 부분을 설명해 줘.
```

## 네 가지 길

| 길 | 이럴 때 | 이렇게 해요 |
| --- | --- | --- |
| 대화로 만들기 | 메모도 파일도 없을 때 | 에이전트의 질문에 답하면서 경험 메모나 현황 메모를 만들고 `data/`에 저장합니다 |
| 가진 자료 주기 | 공고, 메모, 회의록, 파일이 있을 때 | 붙여 넣거나 파일로 줍니다. 원본은 `source/`, 분석할 자료는 `data/`에 둡니다 |
| 에이전트가 찾기 | 쓰는 도구가 검색이나 브라우저를 쓸 수 있을 때 | 찾은 자료의 출처와 확인 날짜, 실제로 읽은 범위를 함께 남기게 합니다 |
| 다른 AI의 정리본 쓰기 | 로그인한 페이지나 영상처럼 에이전트가 못 여는 자료일 때 | 그 페이지를 볼 수 있는 다른 AI(예: Chrome의 Gemini)에게 정리를 부탁해 받아 옵니다. **원문이 아니라 중간 자료**로 표시합니다 |

## 링크와 양식이 정해져 있다면

```text
이 URL의 내용을 templates/05_자료_수집_기록.md 양식에 맞춰 정리해 줘. [자료 URL]
확보한 원본은 source/에, 양식에 맞춘 자료는 data/에 저장해 줘.
원문 링크, 확인 날짜, 실제로 읽은 범위와 확인하지 못한 부분도 적어 줘.
접근하거나 저장할 수 없으면 다른 방법을 알려줘.
```

## 다른 AI에게 정리를 부탁할 때

```text
지금 열어 둔 페이지나 영상에서 네가 확인할 수 있는 내용만 정리해 줘.
제목, 원문 링크, 확인한 범위와 확인하지 못한 부분을 함께 적어 줘.
추측하지 말고 AI가 작성한 정리본이라고 표시해 줘.
```

받은 답을 에이전트에게 건네며 "다른 AI가 만든 중간 자료로 data/에 저장해 줘"라고 하면 됩니다.

## 회사 자료와 연결된 도구

- 이메일이 `.eml` 파일로 있으면 원본은 `source/`에 두고, 내용은 `templates/04_업무_소통과_진행_기록.md` 양식으로 정리할 수 있습니다. 첨부파일을 실제로 읽었는지도 따로 확인하세요.
- Slack이나 Notion 같은 도구가 연결되어 있으면, 내가 지정한 범위의 자료만 가져오게 할 수 있습니다. 연결이 없으면 파일이나 메모를 직접 주면 됩니다.
- 회사의 AI 사용 기준과 내 권한을 먼저 확인하세요.

## 꼭 기억할 것

- 링크 주소만 적어 둔 것은 본문을 읽은 것이 아닙니다.
- 에이전트가 접근하지 못한 자료는 읽은 것처럼 다루지 않습니다. 실제로 읽은 범위를 물어보세요.
- 원문, 내가 준 메모, AI가 만든 정리본은 서로 구분해 둡니다.
- 비밀번호나 인증번호는 대화에도 파일에도 적지 않습니다.
