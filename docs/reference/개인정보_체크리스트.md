# 개인정보 체크리스트

자료를 AI에게 올리기 전에 한 번만 훑어보세요. 이 체크리스트는 AI가 아니라 **내가** 확인하는 것입니다. AI에게 점검을 부탁해도 되지만, 최종 확인은 사람이 합니다.

## 올리기 전에 지우거나 가릴 것

- [ ] 이름, 주민등록번호, 여권·운전면허 번호
- [ ] 전화번호, 이메일, 집 주소
- [ ] 계좌·카드 번호, 비밀번호, 인증번호, 로그인 정보
- [ ] 회사 기밀, 고객 이름·연락처, 내부 문서의 민감한 내용
- [ ] 이력서의 사진, 생년월일, 가족 정보

가리는 예: `김OO`, `A회사`, `고객 1`, `010-****-****`. 가린 자료로도 대부분의 연습은 충분히 할 수 있어요.

## 회사 자료라면

- [ ] 회사의 AI 사용 기준을 확인했나요? (외부 AI에 올려도 되는 자료인지)
- [ ] 올려도 된다는 권한이 있나요?
- [ ] 실제 자료 대신 가상 자료나 비식별 자료로 연습할 수 있을까요?

## 도구 설정 확인

- [ ] 사용하는 AI 앱에서 내 대화와 파일이 어떻게 쓰이는지 설정 화면에서 확인했나요? 도구와 요금제에 따라 다르므로 직접 확인해 주세요 `[확인 필요]`
- [ ] 파일이 내 컴퓨터의 어느 폴더에 저장되는지 알고 있나요? (`source/`, `data/`, `outputs/`)

## 실수로 올렸다면

1. 에이전트에게 어떤 파일에 들어갔는지 알려 달라고 하세요.
2. 작업공간의 해당 파일(`source/`, `data/`, `outputs/`)에서 가린 파일로 바꾸세요. 파일을 지울 때는 에이전트가 먼저 확인을 요청해요.
3. 비밀번호나 인증정보라면 지체 없이 바꾸세요.

AI에게 이렇게 부탁할 수 있습니다.

```text
이 자료를 올리기 전에 이름·연락처·주소·계좌처럼 개인정보로 보이는 부분이
있는지 먼저 찾아서 알려줘. 고치는 건 내가 확인한 뒤에 해 줘.
```
