# 방법론 한눈에 보기

같은 고민도 여러 방법으로 풀 수 있어요. 아래 표에서 내 고민에 가까운 줄을 찾아 보세요. 방법 이름을 몰라도 괜찮고, 하나만 쓰거나 여러 개를 이어 써도 됩니다. 어떤 방법이 맞을지 모르겠다면 이렇게 말해 보세요.

```text
이 고민에 쓸 수 있는 방법을 2~3가지만 골라서, 각각 어떤 결과가 나오는지
쉽게 알려줘. 내가 고를게.
```

| 이런 고민이라면 | 쓸 수 있는 방법 | 얻는 결과 | 도구 상자 |
| --- | --- | --- | --- |
| 뭐가 문제인지 모르겠다 | 먼저 진단하기, 문제를 작게 나누기 | 다룰 문제 하나와 첫 단계 | `thinking-toolkit` |
| 하고는 있는데 진행이 안 된다 | 막힌 단계 찾기 | 막힌 단계 하나와 바로 해 볼 것 | `thinking-toolkit` |
| 문제가 커서 어디부터 풀지 모르겠다 | 큰 문제 정리하기(나누고 고르기, 원인 따라가기, 바라는 모습과 차이 보기, 다 적고 묶기) | 고른 방법에 따른 정리 | `thinking-toolkit` |
| 아이디어가 없거나 밋밋하다 | 생각 넓히기(문제 다시 정의, 스캠퍼, 다른 분야에서 빌려오기) | 넓힌 아이디어와 고른 두세 개 | `thinking-toolkit` |
| 여러 선택지 중 못 고르겠다 | 내 기준으로 선택 비교, 여러 관점으로 점검하기(큰 결정일 때) | 기준별 비교표, 확인할 가정, 관점별 입장과 핵심 조건 | `thinking-toolkit` |
| 할 일이 많아 뭐부터 할지 모르겠다 | 지금 할 일 하나 고르기 | 지금 할 일 하나와 나중에 할 일 | `thinking-toolkit` |
| 계획이 불안하다 | 미리 어려움 살펴보기(사전 점검) | 놓친 위험과 보완 | `thinking-toolkit` |
| 상대가 어떻게 받아들일지 궁금하다 | 다른 관점에서 보기 | 상대 입장의 질문과 걱정 | `thinking-toolkit` |
| 첫 결과가 아쉽다 | 첫 결과 개선하기 | 고칠 점 최대 3개와 방법 | `thinking-toolkit` |
| 무엇을 원하는지·목표를 어떻게 세울지 막막하다 | 그로우, 만다라트, 스마트 목표, 목표와 핵심 결과, 배우는 목표 | 다음 행동과 확인 기준이 있는 목표 | `goal-achievement-toolkit` |
| 마감까지 준비할 일이 막막하다 | 역산 계획 | 거꾸로 나눈 준비 단계 | `goal-achievement-toolkit` |
| 계획은 있는데 실천이 잘 안 된다 | 우프, 실행 의도, 해빗 스태킹, 새 출발 효과, 유혹 묶기 | 걸림돌 대응과 시작 계기 | `goal-achievement-toolkit` |
| 해 본 계획을 점검하고 싶다 | 돌아보기와 조정 | 이어갈지·바꿀지 고른 다음 행동 | `goal-achievement-toolkit` |
| 원서나 긴 자료가 안 읽힌다 | 큰 그림부터 풀어 읽기, 내 수준에 맞춘 설명 | 뼈대·용어 표·한글 요약 | `learning-toolkit` |
| 이해했는지 모르겠다, 비슷한 게 헷갈린다 | 내 말로 설명해 보기, 나란히 놓고 비교하기 | 빈틈 목록, 비교표 | `learning-toolkit` |
| 외울 게 많다, 금방 잊는다 | 문제로 꺼내 보기, 간격을 두고 다시 보기 | 문제와 채점, 복습 기록 | `learning-toolkit` |
| 문제를 못 풀거나 자꾸 틀린다 | 힌트를 받으며 풀기, 틀린 문제 돌아보기(개념 상태 나누기 포함), 섞어서 풀기 | 내 풀이, 틀린 이유, 개념별 상태 | `learning-toolkit` |
| 시험이 다가온다 | 시험 범위로 점검하기, 모의고사 풀기 | 시험 지도, 약한 단원과 볼 순서, 감점 주제표 | `learning-toolkit` |
| 내 경험을 말로 못 하겠다 | 4R, STAR | 역할·행동·결과로 정리한 경험 | `job-search-toolkit` |
| 강점과 준비할 점을 돌아보고 싶다 | SWOT | 네 칸 정리와 다음 행동 하나 | `job-search-toolkit` |
| 공고가 여러 개다 | 공고 비교, 공고와 경험 대조 | 비교표와 연결된 경험 | `job-search-toolkit` |
| 지원할 회사·산업을 알아보고 싶다 | 자료 조사 | 출처가 있는 조사 정리와 질문 | `research-toolkit` |
| 면접이 걱정된다 | 면접 연습 | 예상 질문과 연습 | `job-search-toolkit` |
| 업무 내용이 흩어져 있다 | 업무 소통 기록, 육하원칙 | 번호·날짜·출처가 있는 기록 | `workplace-toolkit` |
| 보고를 써야 한다 | Why–What–How–If, 주간·월간 보고 | 읽는 사람에게 맞춘 보고 | `workplace-toolkit` |
| 회의 내용을 정리해야 한다 | 결정·할 일·기한 나누기 | 실행 목록 | `workplace-toolkit` |
| 회의에 들어가기 전에 준비하고 싶다 | 회의 전 준비 브리프 | 할 일·알아 둘 것·조심할 것 | `workplace-toolkit` |
| 문서마다 숫자가 다르다 | 근거 대조 | 일치·차이·확인 필요 목록 | `evidence-check` |
| 엑셀·CSV 자료가 있다 | 표 자료 살펴보기와 분석 | 정리된 표와 분석 | `data-toolkit` |
| 새 자료가 들어왔다 | 결과 갱신 | 달라진 점과 새 결과 | `update-workflow` |
| 뭔가 기획하고 싶다 | 문제·대안·위험·초안 | 기획 초안 | `planning-toolkit` |
| 한눈에 보여 주고 싶다 | 인포그래픽 | 구성과 분위기를 고른 이미지 | `infographic-toolkit` |
| 글이 어색하다 | 한글 다듬기 | 다듬은 글과 변경 기록 | `humanize-korean` |
| 긴 결과의 핵심만 보고 싶다 | 핵심부터 전달 | 핵심과 근거 | `clear-summary` |

방법은 정답이 아니라 선택지입니다. 에이전트가 제안한 방법이 맞지 않으면 다른 방법이나 내 방식으로 바꿔 달라고 하세요. 쓰는 에이전트에 따라 도구 상자를 읽는 방식이 다를 수 있어서, 필요하면 "`thinking-toolkit`을 읽고 시작해 줘"처럼 말해도 됩니다.

각 방법을 실제 고민에 써 보는 모습은 [사례집](../01_사례집.md)에서 볼 수 있습니다.
