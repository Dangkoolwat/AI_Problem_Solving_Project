# [업데이트 가이드] 최신 프로젝트로 내 프로젝트 업데이트하기

> **대상**: 이미 `AI_Problem_Solving_Project`를 내려받아 쓰고 있는 수강생
> **프로젝트 주소**: `https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git`
> **내 프로젝트 위치**: Windows `C:\AI_Problem_Solving_Project` · Mac `/Users/내계정이름/AI_Problem_Solving_Project`

이 프로젝트는 강의가 진행되면서 지침, 스킬, 안내 문서 등 **시스템 파일이 계속 업데이트**됩니다. 아래 방법을 따르면 **내 작업 폴더 4개는 그대로 지키고, 나머지 시스템 파일만 최신 버전으로 덮어쓸 수 있습니다.** 수강생은 GitHub에 올리는(push) 권한이 없고, 올릴 필요도 없습니다.

## 1. 무엇이 지켜지고, 무엇이 바뀌나요?

| 구분 | 대상 폴더·파일 | 업데이트 시 동작 |
| --- | --- | --- |
| **내 작업 영역 (보존)** | `source/`, `data/`, `outputs/`, `agents_logs/` (작업 기록과 `INDEX.md` 포함) 및 내가 새로 만든 커스텀 스킬 폴더(`.skills/my-이름/`) | **그대로 유지**됩니다. (단, 직접 `git commit`한 파일은 업데이트 때 지워질 수 있으니 에이전트나 본인이 임의로 커밋하지 마세요.) |
| **시스템 영역 (최신 상태로 맞춤)** | `AGENTS.md`, `README.md`, `docs/`, `instructions/`, 기존 `.skills/`, `templates/` 등 그 외 전체 | **강사가 올린 최신 상태로 그대로 맞춰집니다.** 내가 직접 고친 부분도 되돌아가고, 저장소에 없는 시스템 파일은 정리됩니다. |

> **나만의 워크플로우로 고쳐 쓰고 싶을 때**
> 1. 기존 스킬 폴더를 직접 고치면 업데이트할 때 원래대로 되돌아갑니다. 기존 스킬을 복사해 **`.skills/my-이름/`처럼 새 폴더 이름**으로 만드세요.
> 2. 복사한 폴더 안 `SKILL.md` 맨 위의 `name:`도 새 이름(`my-이름`)으로 바꿔야 원래 스킬과 헷갈리지 않습니다.
> 3. 새로 만든 스킬은 자동으로 읽히지 않으므로, 쓸 때 에이전트에게 **`.skills/my-이름/SKILL.md를 읽고 시작해 줘`**라고 말해 주세요.

## 2. 업데이트 전 필수 준비 (Git · ZIP 공통)

업데이트를 시작하기 전에 아래 두 가지를 꼭 먼저 하세요.

1. **VS Code와 AI 에이전트 앱을 모두 닫습니다.** (Claude Desktop, ChatGPT, Antigravity 등) 프로그램이 폴더를 열고 있으면 파일이 잠겨 오류가 나거나 작업 중 파일이 꼬일 수 있습니다.
2. **내 작업 폴더를 다른 곳에 복사해 백업합니다.** `source`, `data`, `outputs`, `agents_logs` 4개 폴더(직접 만든 `.skills/my-...` 폴더가 있다면 함께)를 OneDrive·iCloud와 연결되지 않은 폴더에 복사해 두세요. 업데이트가 잘 끝난 뒤에 지워도 됩니다.
   - **Windows**: `C:\AI_backup_날짜` (바탕화면·문서 폴더는 OneDrive와 연결될 수 있어 피하세요)
   - **Mac**: 홈 폴더 아래 `/Users/내계정이름/AI_backup_날짜` (바탕화면·문서 폴더는 iCloud와 연결될 수 있어 피하세요)

## 3. Git으로 받은 경우 (추천: 명령 3개로 업데이트)

`git clone`으로 프로젝트를 받았다면 아래 명령을 **한 줄씩** 입력해 시스템 파일만 최신 버전으로 맞춥니다.

> **주의**: `git clean` 같은 삭제 명령은 절대 입력하지 마세요. 아래 두 명령(`fetch`, `reset --hard`)만 사용합니다.

### Windows (명령 프롬프트 `cmd`)

시작 메뉴에서 **명령 프롬프트**(`cmd`)를 엽니다(관리자 권한 아님). 아래 명령을 **위에서부터 하나씩** 복사해 붙여 넣고, 매번 Enter를 누르세요.

1. 프로젝트 폴더로 이동합니다.

   ```text
   cd /d C:\AI_Problem_Solving_Project
   ```

   *(Windows에서 `git`이 인식되지 않아 **Git Bash**를 열었다면, 위 줄 대신 아래 줄을 입력하세요.)*

   ```text
   cd /c/AI_Problem_Solving_Project
   ```

2. GitHub에서 최신 버전을 내려받아 준비합니다.

   ```text
   git fetch origin
   ```

3. 시스템 파일을 강사가 올린 상태로 그대로 맞춥니다(내가 직접 고친 시스템 파일도 되돌아갑니다). `HEAD is now at ...`가 나오면 완료입니다.

   ```text
   git reset --hard origin/main
   ```

### Mac (터미널)

**터미널**을 엽니다(`Command + Space` → `터미널`). 아래 명령을 **위에서부터 하나씩** 복사해 붙여 넣고, 매번 Enter를 누르세요.

1. 프로젝트 폴더로 이동합니다.

   ```text
   cd ~/AI_Problem_Solving_Project
   ```

2. GitHub에서 최신 버전을 내려받아 준비합니다.

   ```text
   git fetch origin
   ```

3. 시스템 파일을 강사가 올린 상태로 그대로 맞춥니다(내가 직접 고친 시스템 파일도 되돌아갑니다). `HEAD is now at ...`가 나오면 완료입니다.

   ```text
   git reset --hard origin/main
   ```

> `source/`, `data/`, `outputs/`, `agents_logs/` 안에 내가 새로 만든 파일은 Git 추적 대상이 아니므로 유지됩니다. 다만 예전 버전에서 처음 업데이트해 `agents_logs/INDEX.md`가 사라졌다면 아래 **5장** 안내대로 백업 폴더에서 `INDEX.md`만 다시 복사해 넣으세요.

## 4. ZIP으로 받은 경우 (수동 업데이트)

Git을 쓰지 않고 ZIP으로 내려받은 경우에는 새 버전을 받은 뒤 내 작업 폴더 4개만 옮깁니다.

1. 브라우저에서 `https://github.com/Dangkoolwat/AI_Problem_Solving_Project`를 열고 **[Code] → [Download ZIP]**을 누릅니다.
2. 받은 ZIP 파일의 압축을 풀고, 풀린 폴더 이름을 임시로 `AI_Problem_Solving_Project_new`로 바꿉니다.
   - **Windows**: `C:\AI_Problem_Solving_Project_new`
   - **Mac**: 홈 폴더(`/Users/내계정이름/AI_Problem_Solving_Project_new`)
3. 기존 `AI_Problem_Solving_Project` 폴더 안에 있는 **`source`, `data`, `outputs`, `agents_logs` 4개 폴더**를 복사해 `AI_Problem_Solving_Project_new` 폴더 안에 붙여 넣습니다.
   - **Windows**: "같은 이름의 파일(`안내.md`)이 있습니다" 창이 뜨면 **건너뛰기**를 선택하면 최신 `안내.md`가 유지됩니다.
   - **Mac (Finder)**: "중단 / 둘 다 유지 / 대치" 창이 뜨면 **대치**를 선택하세요. (**둘 다 유지**를 고르면 `outputs 2` 같은 폴더가 생겨 에이전트가 기존 폴더를 찾지 못합니다.)
   - 내가 직접 만든 커스텀 스킬 폴더(`.skills/my-...`)가 있다면 그것도 새 폴더의 `.skills/` 안으로 함께 복사하세요.
4. `AI_Problem_Solving_Project_new` 안에 내 자료와 최신 `docs/`, `.skills/`가 모두 잘 들어 있는지 확인합니다.
5. **2장**대로 VS Code와 에이전트 앱이 닫혀 있는지 확인한 뒤(열려 있으면 "사용 중" 오류가 납니다), 기존 폴더 이름을 `AI_Problem_Solving_Project_old`로 바꾸고 `AI_Problem_Solving_Project_new` 이름을 **`AI_Problem_Solving_Project`**로 바꿉니다.
6. 새 폴더에서 내 자료와 에이전트 동작이 정상 확인되면 `AI_Problem_Solving_Project_old` 폴더는 지워도 됩니다.

## 5. 업데이트가 잘 됐는지 확인하기

### 방법 1. 터미널에서 최신 날짜 확인 (Git 사용자)

프로젝트 폴더 안에서 아래를 입력하면 가장 최근에 반영된 업데이트 제목과 날짜가 보입니다.

```text
git log -1 --oneline
```

### 방법 2. 내 파일과 최신 문서 확인 (공통)

1. 파일 탐색기(Windows)나 Finder(Mac)에서 `outputs/`, `source/`, `agents_logs/` 안에 내 파일이 그대로 있는지 확인합니다.
   - 만약 `agents_logs/INDEX.md`가 사라졌다면 **2장**에서 백업해 둔 폴더의 `agents_logs/INDEX.md`를 프로젝트의 `agents_logs/` 안으로 다시 복사해 넣으세요.
2. AI 에이전트 대화창에 아래처럼 물어 새 스킬이나 문서가 잘 읽히는지 확인해 보세요.

```text
아직 파일을 수정하지 마.
지금 프로젝트의 AGENTS.md와 .skills/ 목록을 확인해서, 현재 쓸 수 있는 스킬 목록만 짧게 알려 줘.
```

## 6. 자주 생기는 오류

**Q1. `fatal: not a git repository`가 나와요.**
두 가지 중 하나입니다.

1. 프로젝트 폴더 바깥에서 명령을 입력했을 때: 아래 명령으로 먼저 폴더 안으로 들어갔는지 확인하세요.
   - Windows:

     ```text
     cd /d C:\AI_Problem_Solving_Project
     ```

   - Mac:

     ```text
     cd ~/AI_Problem_Solving_Project
     ```

2. 처음에 **ZIP으로 받은 폴더**일 때: ZIP 폴더는 Git 명령을 쓸 수 없으니 위 **4. ZIP으로 받은 경우**대로 업데이트하세요.

**Q2. Windows에서 `'git'은(는) 내부 또는 외부 명령... 이 아닙니다`가 나와요.**
Git PATH가 안 잡힌 상태입니다. 시작 메뉴에서 **Git Bash**를 열고, 아래 명령을 **하나씩** 입력한 뒤 매번 Enter를 누르세요.

1. 프로젝트 폴더로 이동합니다.

   ```text
   cd /c/AI_Problem_Solving_Project
   ```

2. 최신 버전을 내려받습니다.

   ```text
   git fetch origin
   ```

3. 시스템 파일을 강사가 올린 상태로 그대로 맞춥니다(내가 직접 고친 시스템 파일도 되돌아갑니다).

   ```text
   git reset --hard origin/main
   ```

명령 프롬프트(`cmd`)에서도 되게 고치는 근본 해결 방법은 [설치 가이드](00_설치_가이드.md)의 **Q6**을 참고하세요.

**Q3. `Could not resolve host`, `Failed to connect`, `SSL certificate problem`이 나와요.**
인터넷 연결이 끊겼거나 회사·기관 네트워크가 GitHub 접속을 막는 경우입니다. 다른 네트워크(휴대폰 핫스팟 등)에서 다시 시도하거나, 급하면 **4. ZIP으로 받은 경우**로 업데이트하세요. 보안 설정을 끄는 명령은 입력하지 마세요.

**Q4. 업데이트 후 VS Code나 에이전트에 새 내용이 안 보여요.**
VS Code나 에이전트 앱을 한 번 닫았다가 다시 열고, 새 대화를 시작해 보세요.
