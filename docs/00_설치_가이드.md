# [사전 준비 가이드] Windows·Mac에서 프로젝트 내려받기와 AI 에이전트 준비

> **대상**: 20~30 청년다락방 AI 업무 자동화 강의 수강생
> **기준**: Windows 10 / 11 또는 macOS 노트북
> **준비물**: 노트북과 충전기, 인터넷, 사용할 AI 서비스의 계정
> **프로젝트 주소**: `https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git`
> **내려받을 위치**: Windows는 `C:\AI_Problem_Solving_Project`, Mac은 내 계정 홈 폴더의 `AI_Problem_Solving_Project`

이 가이드는 Git으로 프로젝트를 내 컴퓨터에 받고, AI 에이전트에서 그 폴더를 열어 확인하는 데까지 안내합니다. **Windows 사용자는 1장, Mac 사용자는 2장**만 따라 하고, 3장부터는 함께 진행하세요.

스마트폰이나 태블릿만으로는 내 컴퓨터 폴더를 쓰는 실습을 따라가기 어렵습니다. 회사·기관 노트북은 설치나 폴더 쓰기가 막혀 있을 수 있으니 미리 확인해 주세요.

> **안내 기준**: 이 문서는 2026년 11월 기준 공식 안내를 바탕으로 작성했습니다. 설치에서 막히면 뒤쪽 **자주 묻는 문제**를 보고 강사에게 알려 주세요.

## 한눈에 보는 체크리스트

해당하는 항목만 체크하세요. 이미 설치한 프로그램은 동작을 확인했다면 다시 설치하지 않아도 됩니다.

- [ ] 프로젝트를 내려받았어요.
  - Windows: `C:\AI_Problem_Solving_Project`
  - Mac: `/Users/내계정이름/AI_Problem_Solving_Project`
- [ ] 그 폴더 바로 안에 `README.md`, `AGENTS.md`, `docs`, `outputs`가 보여요.

- [ ] 무료 사용자: VS Code를 설치하고 무료로 쓸 수 있는 확장을 연결했어요.

**공통 확인 (4장)**

- [ ] 에이전트가 `README.md`와 `AGENTS.md`를 읽고 맞게 답했어요.
- [ ] 에이전트가 `outputs`에 만든 확인 파일을 직접 열어 봤어요.

## 1. Windows: `C:\`에 프로젝트 내려받기

> **Mac 사용자**는 이 장을 건너뛰고 **2. Mac**으로 가세요.

### 1-1. 파일 확장명 표시 켜기

확장명이 숨겨져 있으면 `AGENTS.md.txt`를 `AGENTS.md`로 착각할 수 있습니다.

1. **Windows 키 + E**를 눌러 파일 탐색기를 엽니다.
2. 사용하는 버전에 맞게 선택합니다.
   - **Windows 11**: 위쪽 **[보기] → [표시] → [파일 확장명]**
   - **Windows 10**: 위쪽 **[보기]** 탭에서 **[파일 확장명]** 체크
3. 같은 메뉴의 **[숨긴 항목]**도 켜 두면 `.skills` 같은 폴더를 볼 수 있습니다.

### 1-2. Git 설치 확인하기

Git은 파일의 변경 기록을 관리하고, 인터넷에 있는 프로젝트를 내 컴퓨터로 받아 오는 도구입니다. 프로젝트를 받기만 할 때는 **GitHub 가입이 필요 없습니다.**

1. 시작 메뉴에서 **명령 프롬프트** 또는 **cmd**를 검색해 엽니다. **관리자 권한으로 실행하지 않습니다.**
2. 아래를 입력하고 Enter를 누릅니다.

   ```text
   git --version
   ```

3. `git version 2.xx.x.windows.x`처럼 버전 번호가 나오면 **1-4. 내려받기**로 넘어갑니다.
4. `'git'은(는) 내부 또는 외부 명령... 이 아닙니다`라는 메시지가 나오면 아래 **1-3. 설치**를 진행합니다.

### 1-3. Git for Windows 설치하기

1. [Git for Windows 공식 다운로드 페이지](https://git-scm.com/download/win)에 접속합니다.
2. 내 PC에 맞는 **Setup** 설치 파일을 받습니다. 대부분의 Intel·AMD PC는 **x64**, ARM 기반 PC는 **ARM64**입니다. 잘 모르겠으면 **[설정] → [시스템] → [정보] → [시스템 종류]**를 확인하세요.
3. 설치 파일을 실행합니다. 보안 경고가 나오면 공식 사이트에서 받은 파일인지, 게시자가 맞는지 확인합니다. 조직에서 막는다면 강사나 관리자에게 문의하세요.
4. 화면 설명을 읽으며 진행합니다. **PATH 환경 조정** 화면에서는 `Git from the command line and also from 3rd-party software`(권장 항목)를 고릅니다. 나머지는 특별한 안내가 없으면 기본값으로 진행해도 됩니다.
5. 설치가 끝나면 **열려 있던 명령 프롬프트를 닫고 새로 열어** `git --version`을 다시 입력합니다. 버전 번호가 보이면 완료입니다.

> **PATH란?** 윈도우가 프로그램을 찾을 때 살펴보는 경로 목록입니다. 보통 설치 과정에서 자동으로 잡힙니다.
>
> **Git을 설치했는데도 `git`이 인식되지 않나요? (PATH가 안 잡힌 경우)**
>
> 1. **창 다시 열기**: 열려 있던 명령 프롬프트(`cmd`)와 VS Code를 완전히 닫고 새로 열어 `git --version`을 다시 입력합니다.
> 2. **가장 빠른 우회(Git Bash 쓰기)**: 시작 메뉴에서 **Git Bash**를 검색해 엽니다. Git Bash는 PATH가 안 잡혀 있어도 바로 동작합니다. 아래 두 명령을 하나씩 입력하고 Enter를 누르세요.
>
>    C 드라이브 맨 위로 이동:
>
>    ```text
>    cd /c
>    ```
>
>    프로젝트 내려받기:
>
>    ```text
>    git clone https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git
>    ```
> 3. **명령 프롬프트(`cmd`)에서도 되게 고치기(추천)**: Git 설치 파일을 다시 실행해 **PATH 환경 조정** 화면에서 `Git from the command line and also from 3rd-party software`를 고르고 끝까지 진행합니다. 재설치가 어려울 때의 수동 해결책은 뒤쪽 **자주 묻는 문제 Q6**을 보세요.

### 1-4. `C:\`에 프로젝트 내려받기 (git clone)

수업에서는 경로를 똑같이 맞추기 위해 **`C:\` 바로 아래**에 받습니다. 바탕 화면이나 문서 폴더는 OneDrive와 연결되어 있을 수 있어 쓰지 않습니다.

1. 명령 프롬프트를 엽니다(관리자 권한 아님).
2. 먼저 `C:\`에 같은 이름의 폴더가 이미 있는지 확인합니다.

   ```text
   dir C:\AI_Problem_Solving_Project
   ```

   - `파일을 찾을 수 없습니다`가 나오면 정상입니다. 다음으로 넘어갑니다.
   - 폴더 내용이 보이면 **이미 받은 적이 있는 것**입니다. 지우거나 덮어쓰지 말고 [업데이트 가이드](00_업데이트_가이드.md)를 보거나 강사에게 문의하세요.

3. 먼저 C 드라이브 맨 위로 이동합니다. 아래를 입력하고 Enter를 누릅니다.

   ```text
   cd /d C:\
   ```

4. 이제 프로젝트를 내려받습니다. 아래를 입력하고 Enter를 누릅니다.

   ```text
   git clone https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git
   ```

   - `Cloning into 'AI_Problem_Solving_Project'...`가 나온 뒤 `done.`으로 끝나면 성공입니다.

5. 받은 폴더로 들어갑니다.

   ```text
   cd C:\AI_Problem_Solving_Project
   ```

   *(Git Bash를 쓰고 있다면 위 줄 대신 `cd /c/AI_Problem_Solving_Project`를 입력하세요.)*

6. 폴더 안에 파일이 잘 들어 있는지 목록을 확인합니다.

   ```text
   dir
   ```

   `README.md`, `AGENTS.md`, `docs`, `outputs`, `templates` 등이 보이면 완료입니다.

7. 파일 탐색기 주소창에 `C:\AI_Problem_Solving_Project`를 입력하고 Enter를 눌러, 같은 파일이 보이는지 눈으로도 확인합니다.

> **한글 파일 이름이 `\354\225...`처럼 깨져 보이나요?** Git이 한글 이름을 기호로 표시하는 것일 뿐 파일은 정상입니다. 보기 좋게 바꾸려면 한 번만 아래를 입력하세요.
>
> ```text
> git config --global core.quotepath false
> ```

> **`C:\`에 폴더를 만들 수 없다고 나오나요?** 회사·기관 PC는 `C:\` 쓰기가 막혀 있을 수 있습니다. 보안 설정을 바꾸거나 관리자 권한으로 다시 실행하지 말고 강사에게 알려 주세요.

### 1-5. (Git을 쓸 수 없을 때만) ZIP으로 받기

Git 설치가 막힌 PC라면 ZIP으로도 받을 수 있습니다. 다만 ZIP으로 받으면 **나중에 Git 명령어로 간편하게 업데이트할 수 없고, [업데이트 가이드](00_업데이트_가이드.md)의 ZIP 수동 업데이트 절차를 따라야 합니다.**

1. 브라우저에서 `https://github.com/Dangkoolwat/AI_Problem_Solving_Project`를 엽니다.
2. 초록색 **[Code]** 버튼 → **[Download ZIP]**을 누릅니다.
3. 받은 `AI_Problem_Solving_Project-main.zip`을 `C:\`로 옮기고, 오른쪽 클릭 → **[모두 압축 풀기]**에서 위치를 **`C:\`**로 지정합니다.
4. 만들어진 `C:\AI_Problem_Solving_Project-main` 폴더 이름을 **`AI_Problem_Solving_Project`**로 바꿉니다.
5. `C:\AI_Problem_Solving_Project` 바로 안에 `README.md`가 있는지 확인합니다. 같은 이름 폴더가 한 번 더 들어 있으면 강사에게 문의하세요.

Windows 준비를 마쳤다면 **3. 에이전트 준비**로 이동하세요.

## 2. Mac: 내 계정 홈 폴더에 프로젝트 내려받기

> **Windows 사용자**는 이 장을 건너뛰고 **3. 에이전트 준비**로 가세요.

Mac에서는 **내 계정의 홈 폴더**(`/Users/내계정이름`)에 받습니다. 터미널에서는 홈 폴더를 `~`(물결표)로 줄여 씁니다. 바탕 화면이나 문서 폴더는 iCloud와 연결되어 있을 수 있어 쓰지 않습니다.

### 2-1. 파일 확장자와 숨김 파일 보기

1. Finder를 열고 **Finder → 설정(또는 환경설정) → 고급 → 모든 파일 확장자 보기**를 켭니다.
2. Finder 창에서 `Command + Shift + .`(마침표)를 누르면 `.skills` 같은 숨김 폴더가 보였다 숨었다 합니다.
3. 홈 폴더는 Finder에서 `Command + Shift + H`로 바로 열 수 있습니다. 왼쪽 사이드바에 집 모양 아이콘과 내 계정 이름으로도 보입니다.

### 2-2. Git 확인하기

Mac은 Git을 이미 쓸 수 있는 경우가 많습니다.

1. **응용 프로그램 → 유틸리티 → 터미널**을 엽니다. `Command + Space`를 누르고 `터미널` 또는 `Terminal`을 검색해도 됩니다.
2. 아래를 입력하고 Enter를 누릅니다.

   ```text
   git --version
   ```

3. `git version 2.xx.x`처럼 버전 번호가 나오면 **2-3. 내려받기**로 넘어갑니다.
4. **"명령 줄 개발자 도구를 설치하시겠습니까?"** 창이 뜨면 내용을 확인하고 **[설치]**를 누릅니다(Apple 공식 도구, 몇 분 걸림). 설치가 끝나면 터미널에서 `git --version`을 다시 입력해 확인합니다.
5. 창이 뜨지 않고 `xcrun: error`가 나오면 아래를 입력해 설치 창을 직접 띄웁니다.

   ```text
   xcode-select --install
   ```

   설치가 막히면 강사에게 문의하세요.

### 2-3. 홈 폴더에 프로젝트 내려받기 (git clone)

1. 터미널에서 먼저 같은 이름의 폴더가 있는지 확인합니다.

   ```text
   ls ~/AI_Problem_Solving_Project
   ```

   - `No such file or directory`가 나오면 정상입니다. 다음으로 넘어갑니다.
   - 파일 목록이 나오면 **이미 받은 적이 있는 것**입니다. 지우거나 덮어쓰지 말고 [업데이트 가이드](00_업데이트_가이드.md)를 보거나 강사에게 문의하세요.

2. 먼저 내 홈 폴더로 이동합니다. 아래를 입력하고 Enter를 누릅니다.

   ```text
   cd ~
   ```

3. 이제 프로젝트를 내려받습니다. 아래를 입력하고 Enter를 누릅니다.

   ```text
   git clone https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git
   ```

   - `Cloning into 'AI_Problem_Solving_Project'...`가 나온 뒤 끝나면 성공입니다.

4. 받은 폴더로 들어갑니다.

   ```text
   cd ~/AI_Problem_Solving_Project
   ```

5. 현재 위치가 맞는지 확인합니다. (`/Users/내계정이름/AI_Problem_Solving_Project`가 나오면 정상)

   ```text
   pwd
   ```

6. 폴더 안의 파일 목록을 확인합니다. (`README.md`, `AGENTS.md`, `docs`, `outputs`, `.skills` 등이 보이면 완료)

   ```text
   ls -a
   ```

7. Finder에서 `Command + Shift + H`로 홈 폴더를 열고 `AI_Problem_Solving_Project` 폴더가 보이는지 눈으로도 확인합니다. 자주 쓰려면 이 폴더를 Finder 왼쪽 사이드바로 끌어다 놓으세요.

> **한글 파일 이름이 `\354\225...`처럼 깨져 보이나요?** 파일은 정상입니다. 보기 좋게 바꾸려면 한 번만 아래를 입력하고 Enter를 누르세요.
>
> ```text
> git config --global core.quotepath false
> ```

### 2-4. (Git을 쓸 수 없을 때만) ZIP으로 받기

ZIP으로 받으면 나중에 Git 명령어로 간편하게 업데이트할 수 없고, [업데이트 가이드](00_업데이트_가이드.md)의 ZIP 수동 업데이트 절차를 따라야 합니다.

1. 브라우저에서 `https://github.com/Dangkoolwat/AI_Problem_Solving_Project`를 열고 **[Code] → [Download ZIP]**을 누릅니다.
2. 다운로드 폴더의 `AI_Problem_Solving_Project-main.zip`을 두 번 눌러 압축을 풉니다(Safari는 자동으로 풀 수 있습니다).
3. 만들어진 `AI_Problem_Solving_Project-main` 폴더 이름을 **`AI_Problem_Solving_Project`**로 바꾸고, `Command + Shift + H`로 연 **홈 폴더**로 옮깁니다.
4. 폴더 바로 안에 `README.md`가 있는지 확인합니다.

Mac 준비를 마쳤다면 **3. 에이전트 준비**로 이동하세요.

내가 **AI 유료 서비스를 따로 구독하지 않고 무료로 시작하는지**, 아니면 **이미 등록해 쓰고 있는 유료 AI 서비스가 있는지**에 따라 아래에서 하나 이상을 고르세요. 서비스별 한도와 기능은 계정과 시점에 따라 달라질 수 있습니다. 결제나 유료 전환 화면이 나와도 원하지 않으면 진행하지 않아도 됩니다.

### 3-1. 무료 사용자: VS Code 설치와 확장 연결

유료 AI 구독 없이 시작하는 분은 무료 편집기인 **VS Code**를 설치하고 무료 확장을 연결해 사용합니다.

#### 1) VS Code 설치하기

1. [VS Code 공식 다운로드](https://code.visualstudio.com/download)에서 내 운영체제용 설치 파일을 받습니다.
   - **Windows**: 설치 파일을 실행하고 안내대로 설치합니다. 설치 중 **"Code로 열기" 작업을 Windows 탐색기 메뉴에 추가** 항목을 켜 두면 편합니다.
   - **Mac**: 압축을 풀고 `Visual Studio Code`를 **응용 프로그램** 폴더로 옮긴 뒤 실행합니다.
2. `.md` 파일을 열고 미리보기 단축키를 눌러 제목·목록이 정리되어 보이는지 확인합니다.
   - Windows: `Ctrl + Shift + V` / Mac: `Command + Shift + V`

#### 2) 무료 확장 설치하고 로그인하기

확장 화면 열기: Windows `Ctrl + Shift + X` / Mac `Command + Shift + X`

- **GitHub Copilot Free (추천)**: [Copilot 시작 안내](https://docs.github.com/en/copilot/how-tos/manage-your-account/get-started-with-a-copilot-plan)를 따라 GitHub 계정으로 Copilot Free를 켠 뒤, VS Code 확장에서 제공자가 **GitHub**인 `GitHub Copilot`을 설치하고 로그인합니다. (월별 무료 한도 적용)
- **무료 한도 체험 대안**: Google 계정이나 ChatGPT 계정이 있다면, 아래 **3-2(Codex 확장)**나 **3-3(Antigravity 확장)**도 VS Code에 함께 설치해 무료 한도 범위에서 번갈아 쓸 수 있습니다.

> 두 가지 이상 확장을 연결해 두면 한쪽 한도에 도달했을 때 작업 기록(`agents_logs/`)을 남기고 다른 쪽에서 이어 갈 수 있습니다. 서비스 간 대화 내용이 자동으로 공유되지는 않습니다.

#### 3) VS Code에서 프로젝트 열기

프로젝트 폴더 안의 **`AI_Problem_Solving_Project.code-workspace`** 파일로 여는 것이 가장 간단합니다.

- **Windows**: 파일 탐색기에서 `C:\AI_Problem_Solving_Project`를 열고 `AI_Problem_Solving_Project.code-workspace`를 두 번 누릅니다. 열리지 않으면 VS Code에서 **[File] → [Open Workspace from File...]** 또는 **[Open Folder...]**로 `C:\AI_Problem_Solving_Project`를 고릅니다.
- **Mac**: Finder에서 `Command + Shift + H` → `AI_Problem_Solving_Project`를 열고 `AI_Problem_Solving_Project.code-workspace`를 두 번 누릅니다. 열리지 않으면 VS Code에서 **[File] → [Open Workspace from File...]** 또는 **[Open Folder...]**로 홈 폴더의 `AI_Problem_Solving_Project`를 고릅니다.
- **공통 확인**: "이 폴더의 작성자를 신뢰합니까?" 창이 나오면 위 GitHub 주소에서 직접 받은 폴더가 맞는지 확인한 뒤 신뢰를 선택합니다. 왼쪽 탐색기에 `README.md`, `AGENTS.md`, `docs`, `outputs`, `.skills`가 보이면 준비 완료입니다.

**방법 B. VS Code에서 OpenAI Codex 확장 쓰기**

1. **3-1** 안내대로 VS Code를 설치하고 프로젝트 폴더를 엽니다.

이용 가능 여부와 한도는 계정·플랜마다 다릅니다. [프로젝트와 폴더](https://learn.chatgpt.com/docs/projects?surface=app) · [이용 조건](https://learn.chatgpt.com/docs/pricing)

## 4. 공통 확인: 에이전트가 프로젝트를 읽고 저장하는지

설치와 로그인이 됐다고 에이전트가 내 폴더를 읽을 수 있는 것은 아닙니다. **사용할 에이전트마다** 아래 두 가지를 확인하세요.

### 4-1. 읽기 확인

`README.md`와 `AGENTS.md`를 직접 한 번 열어 본 뒤, 에이전트 대화창에 아래 문장을 붙여 넣습니다.

```text
아직 파일을 수정하거나 새로 만들지 마.
지금 열린 프로젝트의 README.md와 AGENTS.md를 읽고,
이 작업공간의 목적과 에이전트가 지켜야 할 안전 규칙을 간단히 알려줘.
```

답변이 실제 파일 내용과 맞으면 **읽기 확인 완료**입니다. "네, 확인했습니다" 같은 인사만으로는 읽었는지 알 수 없습니다.

### 4-2. 저장(쓰기) 확인

1. `outputs` 폴더에 어떤 파일이 있는지 먼저 봅니다. 기존 파일은 덮어쓰지 않습니다.
2. 에이전트에게 아래 문장을 보냅니다.

   ```text
   AGENTS.md의 산출물 파일명 규칙에 따라 outputs 폴더에
   설치 확인용 새 마크다운 파일을 만들고 '설치 확인용 파일입니다.' 한 줄만 적어 줘.
   같은 이름의 파일이 이미 있으면 덮어쓰지 말고 규칙에 맞는 새 이름을 사용해 줘.
   다른 파일은 수정하거나 삭제하지 마.
   ```

3. 승인 요청이 나오면 **저장 위치와 내용**을 확인하고 승인 여부를 고릅니다.
4. 파일 탐색기(Windows)나 Finder(Mac), 또는 VS Code 탐색기에서 `outputs`의 새 파일을 직접 열어 한 줄이 보이면 **저장 확인 완료**입니다.

### 4-3. 이제 시작하세요

확인이 끝났다면 [시작하기](00_시작하기.md)를 열어 첫 말을 건네 보세요. 어떤 고민으로 시작할지 모르겠다면 [사례집](01_사례집.md)에서 가까운 것을 골라 첫 요청문을 그대로 써 보면 됩니다.

## 6. 자주 묻는 문제

### 공통

**Q1. `git clone` 중 `destination path 'AI_Problem_Solving_Project' already exists`가 나와요.**
이미 같은 이름의 폴더가 있다는 뜻입니다. 지우거나 덮어쓰지 마세요. 예전에 받은 폴더라면 [업데이트 가이드](00_업데이트_가이드.md)로 최신화하고, 무엇인지 모르겠다면 강사에게 확인하세요.

**Q2. `Could not resolve host`, `SSL certificate problem`, `Failed to connect`가 나와요.**
인터넷 연결 문제이거나, 회사·기관 네트워크가 GitHub 접속을 막는 경우입니다. 주소를 정확히 입력했는지 확인하고, 다른 네트워크(휴대폰 핫스팟 등)에서 다시 시도해 보세요. 보안 설정을 끄는 명령은 입력하지 말고 강사에게 오류 문구를 알려 주세요. 급하면 **ZIP으로 받기**를 이용합니다.

**Q3. GitHub 아이디와 비밀번호를 물어봐요.**
이 프로젝트는 공개되어 있어 로그인 없이 받을 수 있습니다. 주소를 잘못 입력하면 로그인 창이 뜰 수 있으니 `https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git`과 한 글자씩 대조해 보세요. 비밀번호는 입력하지 말고 창을 닫습니다.

**Q4. `.skills` 폴더나 `AGENTS.md`가 안 보여요.**
올바른 프로젝트 폴더를 열었는지 확인합니다. Windows는 탐색기 **[보기]**의 숨긴 항목, Mac은 Finder의 `Command + Shift + .`으로 숨김 폴더를 표시합니다. `AGENTS.md.txt`처럼 확장자가 두 번 붙지 않았는지도 확인하세요.

**Q5. 에이전트가 파일을 못 만들거나 `Permission denied`가 나와요.**
에이전트에 연결된 폴더 경로가 위 프로젝트 폴더가 맞는지, 파일 접근 승인을 했는지 확인합니다. 관리자 권한으로 다시 실행하기 전에 강사에게 문의하세요.

### Windows

**Q6. Git을 설치했는데도 `git --version`이나 `git clone`이 인식되지 않아요. (PATH가 안 잡힌 경우)**
아래 순서대로 하나씩 해 보세요.

1. **창 완전히 닫고 다시 열기**: 명령 프롬프트(`cmd`)와 VS Code를 모두 닫고 새로 연 뒤 `git --version`을 다시 입력합니다.
2. **Git Bash로 바로 실행하기(가장 빠름)**: 시작 메뉴에서 **Git Bash**를 검색해 엽니다. Git Bash에서는 PATH가 안 잡혀 있어도 바로 됩니다. 아래 명령을 하나씩 입력하고 Enter를 누르세요.

   C 드라이브 맨 위로 이동:

   ```text
   cd /c
   ```

   프로젝트 내려받기:

   ```text
   git clone https://github.com/Dangkoolwat/AI_Problem_Solving_Project.git
   ```

3. **Git 다시 설치해 PATH 자동 복구(가장 안전)**: [Git for Windows](https://git-scm.com/download/win) 설치 파일을 다시 실행해 **PATH 환경 조정** 화면에서 `Git from the command line and also from 3rd-party software`를 선택하고 끝까지 설치한 뒤 명령 프롬프트를 새로 엽니다.
4. **재설치가 어렵고 수동으로 확인해야 할 때**:
   - 명령 프롬프트에서 아래를 입력해 `git.exe` 파일이 있는지 확인합니다.

     ```text
     dir "C:\Program Files\Git\cmd\git.exe"
     ```

   - 위 위치에 없으면 아래 위치도 확인합니다.

     ```text
     dir "%LOCALAPPDATA%\Programs\Git\cmd\git.exe"
     ```

   - 지금 열린 창에서만 임시로 쓰려면 아래를 입력합니다(창을 닫으면 원래대로 돌아가 안전합니다).

     ```text
     set PATH=%PATH%;C:\Program Files\Git\cmd
     ```

   - 이어서 아래로 버전이 나오는지 확인합니다.

     ```text
     git --version
     ```

   - 영구 등록이 필요하면 Windows 검색에서 **계정의 환경 변수 편집**을 열어 **사용자 변수**의 `Path` → **[편집]** → **[새로 만들기]**로 위 `cmd` 폴더 경로만 추가합니다. 기존 항목은 절대 지우지 마세요.

**Q7. `Filename too long` 오류가 나와요.**
Windows의 경로 길이 제한 때문입니다. `C:\` 바로 아래에 받으면 보통 생기지 않지만, 나온다면 한 번만 아래를 입력하고 다시 받아 보세요.

```text
git config --global core.longpaths true
```

**Q8. `cd C:\`를 했는데 위치가 바뀌지 않아요.**
명령 프롬프트가 다른 드라이브(D: 등)에 있을 때 생깁니다. `cd /d C:\`처럼 `/d`를 붙이세요. PowerShell을 쓰고 있다면 `cd C:\`만으로 됩니다.

**Q9. `ExecutionPolicy` 오류가 나와요.**
PowerShell의 스크립트 실행 관련 오류일 수 있습니다. 실행 정책을 바꾸지 말고, 오류 문구와 직전 동작을 기록해 강사에게 알려 주세요. 이 가이드의 명령은 **명령 프롬프트(cmd)**에서 입력하면 됩니다.

### Mac

**Q10. `xcrun: error: invalid active developer path`가 나와요.**
macOS를 업데이트한 뒤 자주 생깁니다. 터미널에서 아래를 입력하고 Enter를 눌러 명령 줄 개발자 도구를 다시 설치하세요.

```text
xcode-select --install
```

**Q11. 홈 폴더가 어디인지 모르겠어요.**
Finder에서 `Command + Shift + H`를 누르면 열리는 폴더가 홈 폴더입니다. 터미널에서 전체 경로를 보려면 아래 명령을 하나씩 입력하고 Enter를 누르세요.

홈 폴더로 이동:

```text
cd ~
```

현재 경로 확인 (`/Users/내계정이름` 형태로 표시):

```text
pwd
```

**Q12. 앱이 "확인되지 않은 개발자"라며 열리지 않아요.**
공식 사이트에서 받은 앱인지 먼저 확인합니다. 보안 설정을 끄지 말고 강사에게 문의하세요.
